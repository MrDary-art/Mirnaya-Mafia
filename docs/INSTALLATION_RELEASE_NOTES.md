## Установочная сборка для проверки

Исправление 2026.09.28.2: понятное восстановление после ошибки DNS, установка
Ubuntu одной командой, меню управления, автоматический публичный HTTPS и
отдельный тестовый HTTPS по IP. Добавлены экспорт сертификата и инструкция
доверия на пользовательском устройстве; проверка TLS не отключается.

Сайт с отдельной админкой, сохранённой аналитикой, локальным Whisper Tiny,
озвучкой Дмитрия и подключаемым внешним Whisper large-v3-turbo.

Скачайте архив `arena-install-*.zip`, соответствующий `.sha256` и установщик
вашей системы. ZIP уже содержит собранный интерфейс. Модели и изолированный
Python установщик получает сам, с проверкой контрольных сумм.

**Пошаговая инструкция:** [docs/INSTALLATION.md](https://github.com/MrDary-art/Mirnaya-Mafia/blob/main/docs/INSTALLATION.md).

Это предварительный установочный релиз. Локально проверены миграции, доступ,
протокол очереди, сборка, реальный CPU Whisper и Piper. Установка системных служб
на чистой Ubuntu/Windows VM, HTTPS-домен и реальная GPU требуют проверки на
целевой машине владельцем. Успешный CI не означает выполненный тест GPU.

Персональные ключи и базы в архив не входят. Authorization Key вводится скрыто
при установке либо в админке. Готовые сценарии работают без него.
