## Установочная сборка для проверки

Установщик внешнего Whisper теперь принимает адрес сайта без `https://`, повторяет
ввод после ошибки кодировки терминала и продолжает прерванную установку без
повторной загрузки проверенного комплекта. Анимация совы на главной странице
перекодирована в 24 кадра/с; цикл ожидания возвращается к начальной позе плавно.

Добавлена необязательная почта: настройка SMTP для почтового ящика или своего
домена в админке, подтверждение адреса, вход по подтверждённой почте,
восстановление пароля и письма для встреч 1×1. Пока почта выключена,
пользовательские почтовые поля не показываются. Секрет SMTP хранится
зашифрованным в настройках сервера. В админке видна очередь отправки.
Миграция базы данных — `0031`; существующие пользователи сохраняются.
Установщик теперь спрашивает о почте при первом запуске. Повторный запуск
одной команды обновляет уже установленный сайт с резервной копией и снова
предлагает настроить почту; удалять данные для обновления не нужно.

Исправлены переключение вкладок «Пользователи» и «Сессии и отчёты» в админке,
удалено всплывающее уведомление «Сайт установлен». При сбое браузерной службы
голосовые сообщения используют локальный Whisper; запись сохраняется до отправки.
Переключение вкладок, открытие переписки, резервное распознавание и отмена записи
проверены в браузере с тестовыми API и искусственным микрофоном.

Текущая версия: установка сайта и отдельного Whisper на Ubuntu одной командой
из [README](https://github.com/MrDary-art/Mirnaya-Mafia#ubuntu-site).
Добавлена поддержка Ubuntu 22.04/24.04/26.04 LTS и Windows worker.
Комплект публикуется после проверок кода и сборки. Это не заменяет проверку
чистой установки на конкретном сервере и запуск на реальной GPU.

### История предыдущих сборок

Исправление 2026.09.28.3: корректный WorkingDirectory в systemd, проверка служб
перед запуском, доступные для записи каталоги Caddy и явное завершение загрузки
моделей. Службы проверены на реальной Ubuntu 24.04; домен 24projects.ru получил
сертификат Let's Encrypt. Проверены HTTPS, регистрация, вход, сценарий, отчёт,
Whisper Tiny, Piper и авторизация GigaChat. GPU на этом сервере отсутствует.

Исправление 2026.09.28.2: понятное восстановление после ошибки DNS, установка
Ubuntu одной командой, меню управления, автоматический публичный HTTPS и
отдельный тестовый HTTPS по IP. Добавлены экспорт сертификата и инструкция
доверия на пользовательском устройстве; проверка TLS не отключается.

Сайт с отдельной админкой, сохранённой аналитикой, локальным Whisper Tiny,
озвучкой Дмитрия и подключаемым внешним Whisper large-v3-turbo.

Скачайте архив `arena-install-*.zip`, соответствующий `.sha256` и установщик
вашей системы. ZIP уже содержит собранный интерфейс. Модели и изолированный
Python установщик получает сам, с проверкой контрольных сумм.

**Пошаговая инструкция:** [docs/INSTALLATION.md](https://github.com/MrDary-art/Mirnaya-Mafia/blob/main/docs/INSTALLATION.md).

Это предварительный установочный релиз. Проверены миграции, доступ,
протокол очереди, сборка, CPU Whisper и Piper. Службы Ubuntu и публичный HTTPS
дополнительно проверены на сервере владельца. Владелец подтвердил запуск
large-v3-turbo на выделенной NVIDIA RTX 4090, проверку распознавания и статус
worker в админке. Чистая Windows VM остаётся отдельной проверкой.

Персональные ключи и базы в архив не входят. Authorization Key вводится скрыто
при установке либо в админке. Готовые сценарии работают без него.
