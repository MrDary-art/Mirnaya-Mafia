# Проверка установки на сервере

Дата: 28 сентября 2026 года, московское время.
Релиз: `install-v2026.09.28.3`.

## Что проверено

Проверка выполнена на Ubuntu 24.04.5, x86_64, 4 CPU, 8 ГБ ОЗУ, без NVIDIA GPU.
Установщик скачан из опубликованного GitHub Release и запущен обычной командой из [инструкции](INSTALLATION.md).

- Новая установка завершилась с кодом `0`. Заново созданы окружение Python, база, администратор, службы; скачаны модели и зависимости.
- От предыдущей установки сохранён только кеш сертификата Caddy, чтобы не запрашивать повторный сертификат при каждом тесте.
- `arena-api` и `arena-web` включены в автозапуск и работают. В журнале новых служб ошибок нет.
- `https://24projects.ru` открылся с доверенным публичным сертификатом. Главная страница, JavaScript и `/api/health` вернули HTTP 200.
- Работают регистрация, вход, сценарий, выбор ответа и получение отчёта.
- Обычный пользователь не получает доступ к административной аналитике. Администратор не запускает игровые сессии.
- Через административный HTTP API получен WAV от Piper и расшифровка Whisper. Проверка короткого тестового аудио заняла 0,77 секунды; это не оценка скорости любых записей.
- GigaChat вернул настоящий ответ на короткий тестовый запрос.

Внешний Whisper на NVIDIA GPU на этом сервере не проверялся: GPU отсутствует.
Успешный запуск служб и настройка автозапуска проверены без перезагрузки всей машины.

## Исправленные ошибки

- Убраны shell-кавычки вокруг `WorkingDirectory` в systemd: они приводили к `bad unit file setting`.
- Для Caddy указаны доступные для записи каталоги конфигурации и кеша.
- Перед запуском установщик проверяет unit-файлы через `systemd-analyze verify`.
- В CI добавлена проверка настоящим парсером systemd на Linux.
- Загрузка ресурсов теперь явно сообщает о завершении проверки файла.

## Повторная проверка

Перед публикацией следующих установочных релизов нужны успешные CI-проверки, установка опубликованного архива на тестовый сервер и проверка сайта по внешнему HTTPS-адресу. Проверять также вход, права доступа, офлайн-сценарий, отчёт, распознавание и озвучку. GigaChat проверять реальным коротким запросом при наличии ключа.

Пароли и ключи для проверки не хранятся в репозитории. По просьбе владельца тестовая установка после проверки удаляется, чтобы он мог установить проект самостоятельно.
