# Практика с ИИ, сова-ментор и подробный разбор

Основа: main e8bb79c. Локальная ветка: practice-mentor-detailed-report.
Для сравнения формата изучен ReportDocument конца сентября (d0270e8, 29 сентября).

## Поведение

- Убрана безусловная замена сгенерированного начала переговоров общей приветственной фразой.
- При добавленном объёме и неизменной дате заказчик защищает исходный срок, не предлагая уступку за игрока.
- Целиком вставленная подсказка распознаётся в текстовом и потоковом режиме: ИИ просит сформулировать собственное предложение. За текст подсказки не начисляются новые баллы переговорных техник.
- После десяти сообщений ИИ получает инструкцию двигаться к конкретному решению. Число сообщений само по себе не завершает переговоры.
- Согласованный следующий шаг или взаимный отказ проверяются по дословным цитатам обеих сторон и отдельным запросом к аналитику. Следующий шаг не считается достижением всей цели.
- Численные правила метрик и награды не менялись; данные остаются на сервере.

## Экран

Подписи ИИ, кнопка озвучки с SVG вместо символа-эмодзи, исправленная инструкция для голосового ответа. Убраны повторяющиеся роли и лишняя ссылка.

Ментор получил фото совы из главного экрана, короткое приветствие, явное предупреждение об учёте помощи и постепенное появление ответа. Убраны подписи о личном вопросе/чате. Учитывается настройка уменьшения движения; прокрутка вверх останавливает следование за новым текстом. Исправлен контраст карточки.

## Разбор и PDF

На экран и в PDF передаются одни данные: задача, цель, ограничения, помощь ментора, динамика метрик, все принятые аналитические эпизоды, цитаты, ответ ИИ, альтернативы, условия договорённости, рекомендации и полная запись по ходам.

Аналитические эпизоды принимаются только с цитатой из реального хода. Полнота анализа показана отдельно от полноты стенограммы. Если провайдер недоступен, запись не выдаётся за подробный анализ ИИ.

Старый онлайн-разбор можно обновить без повторных наград. При недоступности нового анализа уже сохранённый подробный разбор сохраняется с предупреждением.

PDF создаётся ReportLab: текст и графики, встроенный кириллический шрифт, таблицы, обложка, колонтитулы и номера страниц. Это отдельная вёрстка документа. Проверен восьмистраничный пример по вымышленной беседе и скачивание через интерфейс.

## Проверка и границы

Проверены тематические тесты практики, проверки соглашений, отчётов, прав доступа к PDF, повторного анализа, сценариев и метрик; production-сборка React; экран тренировки и отчёта в браузере, включая узкий экран.

Тесты провайдеров используют моки. Реальный ответ GigaChat и реальная запись с микрофона здесь не проверялись. В локальном окружении отсутствуют Piper/голосовые модели; существующий тест загрузки Piper требует этой зависимости.

Локальный сайт использует отдельную тестовую базу. Рабочий сайт 24projects.ru не обновлялся, ветки на GitHub не изменялись. Миграция и новые зависимости проекта не требуются.
