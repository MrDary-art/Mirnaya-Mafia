# Единая лесная палитра Арены

История замен: [полный список старых цветов](colors-before-forest.md), [исходный машиночитаемый реестр](colors-before-forest.json).

Палитра применяется ко всем интерфейсам React, отдельному окну звонка, графикам, SVG, эффектам canvas/3D, метаданным браузера, PDF, настройкам компании и цветовым акцентам сериалов. Фотографии людей, лесные иллюстрации, видео и пользовательские материалы сохраняют естественные цвета; цветовые роли интерфейса берутся только из пяти примитивов.

| Примитив | HEX | Роль |
|---|---|---|
| Deep Forest | `#022E24` | Основной текст на светлом фоне, тёмные поверхности и тени |
| Moss Shadow | `#1F4D3A` | Вторичный текст, основные действия, корпоративные карточки |
| Eucalyptus | `#4F8F75` | Контуры полей, графики и декоративные акценты |
| Sage Mist | `#9FC3B2` | Светлые выделения, вторичный текст на тёмном фоне |
| Pale Lichen | `#E7F1EC` | Светлые страницы и поля, текст на тёмном фоне |

Канонические переменные: `frontend/src/design/tokens.css`. Старые имена `--sage-*`, `--paper-*`, `--accent-*` и классы Tailwind сохранены как совместимые ссылки на новую палитру. Стандартная цветовая шкала Tailwind и его чёрные тени заменены, поэтому утилиты не возвращают прежние оттенки. Полупрозрачные подложки и `color-mix` используют только эти пять цветов.

## Читаемые сочетания

| Текст | Фон | Контраст |
|---|---|---:|
| Deep Forest | Pale Lichen | 12.82:1 |
| Moss Shadow | Pale Lichen | 8.34:1 |
| Deep Forest | Sage Mist | 7.70:1 |
| Moss Shadow | Sage Mist | 5.01:1 |
| Pale Lichen | Deep Forest | 12.82:1 |
| Pale Lichen | Moss Shadow | 8.34:1 |
| Sage Mist | Deep Forest | 7.70:1 |
| Sage Mist | Moss Shadow | 5.01:1 |

Eucalyptus на Pale Lichen даёт 3.30:1: он подходит для контура поля, крупного значка или линии графика, но не используется для обычного мелкого текста. Кнопки и поля имеют отдельные заливку и контур; светлый текст применяется только на достаточно тёмных поверхностях. Состояния сохраняют подписи, значки и структуру, а не различаются только оттенком.

## Проверки

- `node frontend/scripts/audit-forest-palette.mjs --built` — после сборки ищет значения вне пяти примитивов в исходниках и итоговом CSS, включая RGB, числовые цвета Three.js, SVG и backend-представление. Реестр «до», технический полностью прозрачный цвет и невидимые чёрно-белые маски ластика исключены из проверки. Маски сохраняют правильное стирание рисунка, не затрагивая фон, фото и текст.
- Из `frontend`: `node scripts/verify-forest-palette.mjs` — открывает публичные страницы, личную Арену, администратора и корпоративные разделы на 1440 и 390 px, сохраняет снимки и проверяет контраст текста на однотонных поверхностях. Изображения и сложные композиции требуют визуальной оценки снимков. Проверяются доступные состояния текущей локальной базы, включая первоначальную смену пароля администратора.
- Из `frontend`: `npm.cmd run build`.
- Из `backend`: `python -m pytest -q tests/test_company_certificate_pdf.py tests/test_business_demo.py`.

Результат миграции: в 414 проверяемых исходных файлах и итоговом CSS нет значений вне палитры. Браузерная проверка 58 маршрутов на двух ширинах дала 116 снимков: проверено 5818 текстовых элементов на однотонных поверхностях, оставшихся нарушений контраста, ошибок JavaScript и горизонтального переполнения не найдено. Сложные фоны просмотрены по снимкам. Сборка успешна, восемь backend-проверок пройдены.

Снимки и подробный браузерный отчёт находятся в `.cache/forest-palette/final/`. Границы полей и фокус первого входа администратора проверены отдельно. Механический дизайн-детектор дополнительно сохранил в `.cache/forest-palette/detector.json` эвристические замечания к исходному оформлению; выбранная пользователем палитра и композиция сохранены.
