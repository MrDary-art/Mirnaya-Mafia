# Карта переноса прежнего проекта

Старая реализация сохранена в истории Git (срез `190b893`). Рабочая версия находится в `apps/` и `packages/`. Контент переносится с указанием исходного коммита, а существующая новая SQLite-база расширяется только миграциями. Историческую базу данных приложение не импортирует.

Схема новой базы имеет таблицу `schema_migrations`; миграции 1–7 добавляют обучение, ИИ-диалоги, социальные данные, комнаты, теорию, магазин, формат парного ИИ-собеседования и дерево навыков. Новые таблицы сохраняют ссылки на пользователей; при перезапуске только локальный demo-аккаунт вместе со своими данными удаляется и создаётся заново. Для старой базы требуется отдельный проверенный импорт: резервная копия, сопоставление пользователей и прогресса, сверка количества записей, план возврата. Простое копирование файла поверх `data/arena-v2.db` недопустимо.

Публичное развёртывание пока не готово: локальный SQLite и процессные лимиты должны быть заменены или дополнены для нескольких серверов, сетевой режим требует HTTPS и TURN, внешние ключи остаются только на сервере. При включении внешнего ИИ сценарный офлайн-путь остаётся независимым.
