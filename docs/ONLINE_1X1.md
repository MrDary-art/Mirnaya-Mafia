# Онлайн 1×1

## Режимы

- **Переговоры людей**: два участника получают разные роли и личные цели, проверяют устройства в лобби и переходят в WebRTC звонок.
- **Два интервью с ИИ**: участники получают одинаковый набор вопросов, проходят независимые приватные сессии и после завершения видят личные отчёты. Командный результат является суммой двух результатов.

## Жизненный цикл

`lobby → active → feedback → processing → finished`

Комната стартует, когда наступило назначенное время и оба участника подтвердили готовность устройств. Фоновый обработчик запускает уже готовую запланированную комнату автоматически. Запись личного микрофона начинается только в `active` и только после согласия владельца записи.

Обработка отчёта показывает этапы `queued`, `analyzing`, `building_report`, `ready`. После трёх неудачных попыток отображается `failed` и пользователь может повторить обработку.

## Бронирование

Календарь показывает 14 дней по московскому времени и интервалы по 30 минут. Одно время может использоваться разными парами. Сервер запрещает только пересечение встреч одного и того же участника с учётом полной длительности встречи.

## Данные и приватность

- Личный отчёт и запись доступны только владельцу.
- Отзыв партнёра попадает в чужой отчёт только при явном согласии автора.
- Название команды используется для отображения. Идентификатор пары строится из отсортированных идентификаторов пользователей и остаётся стабильным между встречами.
- Рейтинговый результат публикуется только для режима интервью, сопоставимого сценария и после согласия обоих участников.

## Демо

Демо не создаёт комнату, бронь или рейтинговую запись. Реплики собеседника запрашиваются через настроенную цепочку GigaChat → Ollama → офлайн fallback. Итог рассчитывается серверным анализатором по содержанию ответов и не влияет на профиль.
