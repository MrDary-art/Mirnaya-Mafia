# Enterprise demo guide

Use `/business/demo` for a seeded demonstration. It is isolated from a real company and does not create real memberships, invoices, invitations, or provider traffic.

1. Open the public company entry at `/business` and show the workflow and explicit note that payment is not connected.
2. Open `/business/demo`; use the demo controls to view an employee workflow and a manager workflow.
3. Show assigned practice, launch/resume, results, learning progress, and certificate/report surfaces with seeded data.
4. Show a real workspace only with a prepared test company: department, test employee, role, assignment, published scenario, and completed attempt.
5. Demonstrate the two-company isolation tests through the test suite; do not use cross-tenant real user data for the demo.

Do not claim that the current product includes tenant messaging, scenario reviewer separation, active billing, SSO/HRIS/LMS, a company archive/twin, or mediator/multi-party sessions. The inquiry form stores a lead; it does not automatically send an email.
