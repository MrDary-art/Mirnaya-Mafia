# Сценарий демо для жюри (5 минут)

## Подготовка (до начала)

1. Откройте браузер в режиме инкогнито
2. Откройте ссылку на продакшен-демо
3. Подготовьте вкладки:
   - Главная (/)
   - Настройка (/setup?preset=hr_firing_01)
   - История (/history)
   - README.md (для ссылок на модели)

## 0:00–1:00 — Введение и экран настройки

**Что говорить:**
> «Арена Переговоров — симулятор навыков делового общения. Продукт основан на трёх научных моделях: TKI, Гарвардский метод и теория игр. Мы не просто используем нейросеть — оценка идёт по формальным формулам, которые можно проверить и объяснить.»

**Действия:**
1. Покажите главную страницу
2. Кликните «Новая сессия» → откроется экран настройки
3. Выберите пресет «Увольнение без конфликта»
4. Объясните структуру экрана:
   - Базовые настройки сразу (роль, оппонент, проблематика, цель)
   - Расширенные настройки под кнопкой (отрасль, таймер, скрытая цель)
   - Прогрессивное раскрытие — новичок не видит 15 параметров

**Акцент:**
> «В отличие от ChatGPT, мы оцениваем по Томасу-Килманну, рассчитываем BATNA, определяем стиль поведения в конфликте.»

## 1:00–3:30 — Прохождение сценария

**Что говорить:**
> «Сценарный режим — ядро продукта. LLM не вызывается, каждая реплика предразмечена: TKI, техники, дельты метрик. Это гарантирует скорость, надёжность и воспроизводимость.»

**Действия:**
1. Нажмите «Начать переговоры»
2. Покажите первую реплику оппонента
3. Прочитайте варианты ответов вслух
4. Выберите хороший вариант (сотрудничество)
5. Обратите внимание на всплывающую подсказку тренера-призрака (если включена)
6. Пройдите 3–4 шага, чередуя хорошие и плохие варианты
7. Покажите метрики в реальном времени:
   - Доверие растёт при эмпатии
   - Контроль падает при оправданиях
   - EQ снижается при игнорировании эмоций

**Фишки:**
- Если включён таймер — покажите давление времени
- Если включена скрытая цель — объясните механику угадывания

**Акцент:**
> «Жюри может пройти сценарий за 2–3 минуты. Метрики честные и объяснимые.»

## 3:30–4:30 — Отчёт

**Что говорить:**
> «После сессии — детальный разбор. Не просто "молодец" или "плохо", а конкретные ошибки с альтернативами.»

**Действия:**
1. Дойдите до финала сценария
2. Покажите вердикт (победа/компромисс/провал)
3. Обратите внимание на график метрик (4 линии)
4. Прочитайте 3 ошибки с альтернативами
5. Покажите 2 рекомендации
6. Раскройте «Показать больше»:
   - Карта стилей TKI (распределение по диалогу)
   - Анализ техник (BATNA, объективные критерии)
   - Игровой профиль переговорщика

**Акцент:**
> «Это не психологическая диагностика, а игровой профиль на основе TKI. Честно называем вещи своими именами.»

## 4:30–5:00 — Fallback и надёжность

**Что говорить:**
> «Продукт работает без VPN, без зарубежных карт, без установки. Жюри открывает ссылку и сразу играет. Даже если API недоступен — сценарий проходит в офлайн-режиме.»

**Действия:**
1. Откройте вкладку с локальным запуском (если есть)
2. Или просто скажите:
   > «Отключите интернет — сценарий всё равно работает. GigaChat недоступен — fallback на Ollama. Ollama недоступен — офлайн-реплика из сценария.»

**Финал:**
> «PvP, UGC и рейтинг — в roadmap. Мы осознанно сфокусировались на качественном сценарном режиме с честными метриками, а не на десяти недоделанных фишках.»

## Запасной план

Если деплой упал во время презентации:
1. Откройте видео-запись прохождения (5 минут)
2. Или запустите локально:
   ```bash
   cd backend && uvicorn app.main:app --reload
   cd frontend && npm run dev
   ```
