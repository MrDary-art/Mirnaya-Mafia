## Границы проверки

На рабочем компьютере Windows нет подтверждённого доступа к Ubuntu VM с RTX 4090,
публичному домену и чистой Windows VM. Эти проверки должны оставаться явно
неподтверждёнными до настоящего запуска. Имитация worker проверяет протокол,
но не подтверждает производительность GPU. Релизные команды можно считать
публично доступными только после публикации и проверки реальных артефактов.

## Выполняет владелец на целевом сервере

Пользователь выбрал самостоятельное подключение GPU по инструкции в main.
Поэтому полный запуск на Ubuntu/Windows VM, реальный GigaChat-ключ, HTTPS и
NVIDIA GPU не представлены как выполненные проверки. Порядок действий и
диагностика находятся в INSTALLATION.md. GPU worker не требует входящего порта.
