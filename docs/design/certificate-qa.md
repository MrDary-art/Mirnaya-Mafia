# Проверка дизайна сертификата

Источник: одобренный пользователем зелёный шаблон «Арены переговоров».

Проверено:

- тёмный лесной фон, водопад, арена, сова, рамка и салатовые акценты сохранены;
- в центральном блоке отображается только ФИО из профиля;
- никнейм отображается только в нижних реквизитах с подписью «Ник в Арене»;
- название задания, компания и должность читаются на тёмной панели;
- логотип компании не выводится на сертификате;
- дата, результат, проходной балл и номер формируются из данных сертификата;
- реквизиты отделены от насыщенного фонового изображения;
- предпросмотр сохраняет альбомное соотношение A4;
- скачивание создаёт альбомный PDF из того же фонового изображения и тех же данных;
- длинные значения уменьшаются по размеру, чтобы сохранять безопасные поля.
