# Реестр движения v4

`Реализовано` ниже означает код и хотя бы один живой browser-flow; `частично` — общий переход/состояние есть, но хореография из ТЗ или проверка всех веток отсутствует; `нет` — предметный переход не реализован. Бизнес-результат никогда не создаётся декоративной анимацией. При `prefers-reduced-motion`, выборе «Без эффектов» или отсутствии WebGL новый слой заменяется статическими PNG; DOM остаётся доступным.

| ID | Событие и фактическая реализация | Сокращённая/аварийная ветка | Проверка | Статус |
|---|---|---|---|---|

| T01 | Home section меняет M01–M10 через существующее наблюдение секций | обычный скролл сохранён | весь Home вниз/вверх, `home-finale.png` и видео navigation | Частично: 20–25% overlap/отмена движения не измерены |
| T02 | Существующий Home rail прокручивает к якорям | пользовательский скролл управляет существующим контроллером | rail→AI, sectionTop=0 после движения; видео navigation | Частично: быстрые повторные цели и manual cancel не проверены |
| T03 | Карточка → detail: route motif сменяется, content появляется 520 мс; прямой URL независим от карточки | T00 по прямой ссылке | `/ai`→`/setup`, 5 фаз и видео | Частично: нет настоящего shared-object morph |

| T20 | `Layout` сохраняет scroll для history POP и сбрасывает его для PUSH/REPLACE; Home hash отдаёт существующему контроллеру | route load не зависит от обратного кадра | direct `/#learning`, POP вернул секцию в top=0, Forward `/training` scrollY=0; report/review scrollY=0 | Частично: 160–240 мс reverse-перехода нет |

В новом product-world активный и уходящий мотив сосуществуют только на время перехода. Уходящая геометрия затем освобождается; материалами владеет world-instance. Это простой route/section transition, а не обещанный для всех T03–T20 предметный morph. Пока записаны пять фаз только T03 (`qa-browser/t03-ai-setup-{0,25,50,75,100}.png`) и короткие видео core/learning/blocked booking. Для остальных семейств контрольные фазы и видео остаются долгом.
