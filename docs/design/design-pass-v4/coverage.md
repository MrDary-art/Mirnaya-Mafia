# PRODUCT DESIGN PASS v4 — фактическое покрытие

Состояние рабочего дерева на 25.09.2026. Это журнал проверки, а не перечень обещаний. `B` — реальный браузерный сценарий с действием и снимком/видео; `S` — только статический desktop/mobile снимок работающего приложения; `P` — оформление/логика изменены, но состояние не проверено сквозным браузерным сценарием; `G` — требование остаётся пробелом. Для `S` факт работы всех кнопок не доказан. На всех защищённых маршрутах общий `ProductPage` добавляет заголовок-ориентир, типографику, светлые focus ring, переключатель эффектов и route-мотив; существующая бизнес-логика остаётся в исходном компоненте. На мобильном для 17 базовых маршрутов проверен viewport 390 px и отсутствие document-level horizontal overflow; это не проверка 320 px или экранной клавиатуры.
