# Sharpness audit

Исходные измерения: [`evidence/baseline/measurements.json`](evidence/baseline/measurements.json). Браузер Chrome headless, 1440×900, DPR 1, SwiftShader; это диагностика геометрии, не эталон качества физического устройства.

Пейзаж 1672×941 растянут в Hero до приблизительно 1490×1377 CSS px, в нижних секциях до 1490×1537 CSS px. При `object-fit: cover` реально видимая ширина исходника около 1018 px в Hero и ~916 px в нижней секции; на дисплее DPR 2 это даёт примерно 0.34 и 0.31 исходного пикселя на пиксель экрана. Поэтому повышение DPR Canvas само по себе не устраняет размытие растрового фона.

В v8 для Canvas эффектов добавлен отдельный лимит DPR по выбранной детализации, не связанный с интенсивностью движения. Постеры остались прежними; честное «после» для art-resolution — **без улучшения**, пока не будет 2×/3× зарегистрированных слоёв. Upscale и `image-rendering` не выдаются за исходную детализацию. Нужны варианты для 1440, 1920, 2560, 3840 и portrait/mobile плюс проверки на DPR 1/2/3.
