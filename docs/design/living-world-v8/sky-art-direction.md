# Art direction и открытые решения

Цель — один топографически связный лес: S00 источник и река, S01 перегиб/водопад, S02 чаша, S03 озеро, S04 отражение → небо, S05 открытое небо, S06 кроны, S07 тихая заводь. Текущий постерный набор не соответствует этой карте и не считается master-art.

Временной цикл должен менять только свет и атмосферу **одной** местности. Текущие sky masks являются техническим прототипом: смешанные с уже нарисованным закатом пейзажи оставляют тёплые участки в ночи. Для финала требуются нейтральные diffuse/base слои, отдельные дальние горы/кроны/берега, карта воды, foreground occluders и нарисованные световые passes рассвета/дня/заката/ночи на общей геометрии. Нужна редакторская доводка швов и отражений.

Солнце следует вести относительно горизонта каждого окна; оно не является настоящим AR-указателем погоды/местоположения. Облака и ветер — режиссёрские. UI на рабочих страницах остаётся спокойным, а весь необязательный лесной motion можно отключить.
