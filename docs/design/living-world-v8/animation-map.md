# Animation map

| Система | Сейчас | Условие остановки / следующий шаг |
| --- | --- | --- |
| Суточное небо | **Отключено по запросу**; в UI только заглушка постоянного света. `DaylightDirector` сохранён вне runtime. | Нет загрузки sky masks/clouds и расчёта солнца. Возвращать только вместе с зарегистрированным артом и отдельной приёмкой. |
| Река/озеро | Canvas 2D локально сдвигает полосы исходной воды внутри polygon, даёт тонкие ряби | В static нет новых кадров. Полигонная заливка удалена из-за видимого края. Нужны точные flow maps и отражения. |
| Водопад | Тонкая завеса, струи, ударная рябь и брызги на сцене `scenarios` | Нужен переезд в S01, отдельные source/impact/outflow/occlusion masks. |
| Ветер/листва | Общий сигнал с редкими порывами и scroll impulse, локальная ветка/листья/дымка | Не должны синхронно двигаться все деревья. Нужны иерархические ветви/листья из отдельного art. |
| Сова | Существующий `OwlController` и отдельный WebGL canvas | Не менялась в v8; настройки лесного motion не отключают контроллер совы. |
