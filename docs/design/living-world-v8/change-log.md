# Living World v8 — состояние реализации

Статус: **частичная реализация**, не художественная приёмка полного ТЗ. Ветка `feature/living-forest-v8` создана поверх рабочего v6; предыдущие изменения сохранены.

По последнему запросу пользователя суточная смена **временно отключена**: интерфейс показывает заблокированную заглушку «Постоянный свет». Расчёт солнца, маски неба, облака и световые переходы не входят в runtime главной/входа. Исходники прототипа оставлены для будущего возвращения функции, но не загружаются при обычном посещении.

## Сделано в этом проходе

- Прототип time state, SunCalc 2.0.2 и суточных слоёв сохранён в исходниках и тестах, но выведен из runtime до готовности высокодетального арта и оптимизации.
- Пейзаж теперь освещён статично; настройки движения и детализации эффектов независимы.
- Маски небесных окон desktop/mobile, локальное движение воды, водопада, ветки, листьев и дымки. Убрана заметная полигональная заливка воды после визуальной проверки.
- Загрузка страниц разделена по маршрутам; при открытии главной запрашиваются только текущая и соседняя главы леса. Для слабого/программного WebGL — небольшой статичный кадр той же 3D-совы вместо тяжёлой сцены. Canvas и 3D ограничивают частоту/размер буфера, а при совсем слабом профиле анимация по умолчанию выключена.
- Скриншоты фаз на desktop/mobile и модульные тесты времени относятся к **архивному прототипу до отключения**; не считать их кадрами текущего состояния.

## Не завершено по полному v8

- Нет единой редактируемой высокодетальной вертикальной master-панорамы и независимых зарегистрированных лесных/водных слоёв. Существуют отдельные 1672×941 изображения v6 со встроенным закатным светом. Генерация тестового нейтрального кадра дала тот же размер и сместила геометрию; он не заменил исходник.
- География не приведена к S00–S07: водопад всё ещё в сцене каталога сценариев, а не непосредственно в S01; переходы река → водопад → озеро → небо не являются единым связным рисунком.
- Вода/водопад/кроны реализованы как облегчённый Canvas 2D слой поверх постеров, а не полноценная зарегистрированная 2.5D-система из ТЗ. Нет корректного отдельного отражения солнца и законченного lake → sky.
- Нет проверки на реальном телефоне и аппаратном GPU; нет полного набора 60-секундных видео и художественной оценки по всем экранам/состояниям.
- Ночной кадр местами показывает остатки закатного света из исходного постера/переходного слоя. Это нельзя считать окончательной ночной иллюстрацией.

Следующий необходимый материал: утверждённый послойный master-art 2×/3× с согласованными desktop/mobile crop, отдельными sky/water/foreground и масками либо авторизация полноценной ручной художественной переработки этого набора. Технический контур v8 уже принимает замену ассетов без изменения игровой логики.
