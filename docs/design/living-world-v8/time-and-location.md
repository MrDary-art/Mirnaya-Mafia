# Время, местоположение и вычисления

**Временно не активно в интерфейсе.** По запросу на производительность смена времени суток заменена заглушкой «Постоянный свет». Ни `environmentTimeStore`, ни SunCalc не импортируются текущими экранами. Ниже — контракт сохранённого прототипа для возможного возобновления, не описание работающей функции.

- По умолчанию используется локальное время и timezone устройства: это **художественная** модель восхода, не реальная астрономия для пользователя.
- Режим «По солнцу города» требует явного выбора одного из семи офлайн-пресетов. Координаты — приблизительный центр города; GPS, IP lookup и прогноз погоды не запрашиваются. Presets: Москва, Лондон, Нью-Йорк, Сидней, Кито, Тромсё, Катманду. Источник координат: GeoNames, CC BY 4.0; см. `cityCatalog.js`.
- SunCalc 2.0.2 возвращает apparent altitude в градусах и азимут от севера по часовой стрелке; адаптер переводит это в единый `sun` state. UTC instant хранится отдельно от локальной даты города. События другого локального дня отфильтровываются, при полярном дне/ночи используется высота солнца, а не выдуманный sunrise.
- `SolarClock`: `epochSample + (performance.now() - monotonicSample)`, сверка с `Date.now()` при плановом обновлении, focus и visibilitychange. Визуальное время не меняет игровые таймеры. Окружение обновляется раз в 10 s около горизонта, иначе 30 s; ручная и статичная сцена не запускают постоянные обновления.
- `?forestLab=cycle` доступен только в dev, ускоряет визуальный день до 90 s и помечает надпись «Превью». Глобальные часы браузера не переопределяются.
- Настройки v8 хранятся в `arena_forest_environment_v8`; невалидные значения нормализуются, недоступный storage не ломает интерфейс. Время, движение и качество эффектов разделены. Качество **не** означает наличие 4K-арта.

Версии/единицы: SunCalc 2.0.2; координаты WGS84 decimal degrees; UTC epoch milliseconds; отображение азимута degrees clockwise from north; rendering — CSS px и Canvas backing DPR. [SunCalc](https://github.com/mourner/suncalc), [GeoNames](https://www.geonames.org/export/).
