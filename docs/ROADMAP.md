## Этап 1 (MVP) — ✅ Готово

- [x] Один полноценный сценарий с ветвлением (`hr_firing_01`, 6 шагов)
- [x] Два дополнительных сценария (`salary_talk_01`, `sales_discount_01`)

## Приоритеты

### Для хакатона (следующие 2 недели)
1. **Публичный деплой** — критично для демонстрации
2. **Видео-запись демо** — на случай падения деплоя
3. **Презентация (pptx)** — из `docs/PITCH.md`
4. **Стабилизация таймера** — избежать двойных сабмитов
5. **+2 сценария** — чтобы показать разнообразие

### Для продакшена (1–3 месяца)
1. Геймификация (уровни, экономика звёзд)
2. Личный кабинет с графиком метрик
3. Пресеты на сервере
4. Влияние отрасли/культуры на сценарии
5. Режим хаоса

### Для масштабирования (3–6 месяцев)
1. PvP с рейтингом
2. UGC с модерацией
3. Ежедневный вызов
4. Голосовой режим
5. Мобильное приложение (React Native)
