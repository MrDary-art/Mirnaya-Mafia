# Два собеседования: час на прохождение

Новые комнаты `duel` сохраняют `duel_window_minutes: 60` в существующем JSON состояния. Миграция таблиц не требуется. Старые комнаты без этого поля сохраняют прежний таймер.

1. Оба участника входят и подтверждают готовность. После наступления выбранного времени сервер открывает час.
2. Каждый самостоятельно нажимает «Начать моё собеседование». `POST /api/rooms/{id}/attempt/start` сохраняет начало и личный дедлайн. Повторный запрос не перезапускает таймер.
3. Личная попытка ограничена выбранной длительностью и концом общего часа. До старта и после дедлайна сервер отклоняет ответы, включая общий API текстовых/голосовых сессий.
4. Первый завершивший видит зал ожидания. Второй может независимо начать или продолжить. После обоих завершений (или истечения часа) фоновая задача готовит отчёты.
5. Сравнение получает реальные протоколы обоих. ИИ выбирает A/B/ничью и возвращает каждому объяснение с проверяемой цитатой. Общий вердикт хранится отдельно от личных рекомендаций и не меняет игровые метрики.
6. Если нет ответов одного участника, победитель не определяется. При сбое ИИ личные отчёты доступны, сравнение можно повторить.

Переговоры людей также переходят к анализу автоматически после завершения. Обратная связь больше не блокирует подготовку отчёта.

Демо `/rooms/demo` иллюстративное: зал ожидания и результаты вымышлены и явно подписаны. Реальные комнаты доступны через `/rooms`.

Локальный сервер запускается с одним worker: блокировки изменения JSON комнаты синхронизируют HTTP-запросы и фоновую проверку таймеров внутри процесса. Для нескольких API workers понадобятся распределённые/транзакционные блокировки.

Проверки: `pytest tests/test_room_comparison.py tests/test_room_roles.py tests/test_rooms.py tests/test_room_v2.py -q`; `npm run build`; `node scripts/verify-room-waiting.mjs` (браузерные данные комнат подменены, проверяются состояния интерфейса). Один реальный запрос сравнения GigaChat также проверен отдельно. Полный звонок двух пользователей и аудиомодели этой проверкой не покрыты.
