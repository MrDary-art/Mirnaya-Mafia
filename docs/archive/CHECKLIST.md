## Научная база (для вопросов жюри)

- [ ] **TKI (Thomas-Kilmann, 1974)**
  - 5 стилей: конкуренция, сотрудничество, компромисс, избегание, приспособление
  - Ссылка: https://en.wikipedia.org/wiki/Thomas%E2%80%93Kilmann_Conflict_Mode_Instrument

- [ ] **Гарвардский метод (Fisher, Ury, Patton)**
  - Отделять людей от проблемы
  - Интересы vs позиции
  - BATNA, ZOPA, объективные критерии
  - Ссылка: https://en.wikipedia.org/wiki/Getting_to_Yes

- [ ] **Теория игр (Nash, 1950)**
  - Взвешенная полезность для Confidence
  - НЕ равновесие Нэша как формула!
  - Ссылка: https://en.wikipedia.org/wiki/John_Forbes_Nash_Jr.

## Типичные вопросы и ответы

**Q: Почему нет Big Five?**
> A: Короткий опросник и классификация нейротизма по тексту диалога психометрически невалидны. В отчёте — игровой профиль на TKI, без претензии на диагностику.

**Q: Почему нет PvP в MVP?**
> A: Требует WebSocket, синхронизации состояния, обработки реконнекта. Жюри не сможет проверить за хакатон. Качественный сценарный режим важнее десяти недоделанных фишек.

**Q: Как работает fallback?**
> A: GigaChat (основной) → Ollama (резерв) → офлайн-сценарий (гарантированный). Невалидный JSON анализатора → rule-based парсер по ключевым словам.

**Q: Почему SQLite, а не PostgreSQL?**
> A: Для MVP достаточно. WAL-режим, aiosqlite, SQLAlchemy. При масштабировании — миграция на PostgreSQL через Alembic.
