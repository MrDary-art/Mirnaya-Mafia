# Питч: Арена Переговоров

## 1. Аудитория
HR и менеджеры по продажам: высокая частота сложных разговоров, измеримая боль.

## 2. Проблема
Лекции не тренируют формулировки. Тренер дорог. Нет повторного прохода. Оценка субъективна.

## 3. Решение
Симулятор: роль × оппонент × контекст. Ядро — офлайн-сценарий с ветвлением. После сессии — отчёт по TKI и Гарварду.

## 4. Механика
3–4 варианта на шаг. Каждому варианту заранее проставлены TKI, техники, Δ метрик. Confidence = 0.5 Goal + 0.3 Trust + 0.2 Control.

## 5. Почему не ChatGPT
Вердикт считается формулами. LLM — только свободный диалог. Fallback: GigaChat → Ollama → сценарий. Без VPN и карт жюри открывает ссылку и играет.

## 6. Границы MUP
Делаем: один (плюс два коротких) сценарий, настройка, метрики, отчёт, админ, тесты, деплой.
Не делаем: PvP, UGC, рейтинг, голос, Big Five.

## 7. Технологии
React/Vite/Tailwind · FastAPI · SQLite WAL · Alembic · опционально GigaChat.

## 8. Roadmap
v1.1: больше сценариев, онлайн, кабинет, тренер, таймер.
v2.0: PvP с ИИ-судьёй, UGC, рейтинг, голос, ежедневный вызов.
