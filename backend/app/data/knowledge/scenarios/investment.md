# Инвестиционные переговоры

## Назначение
Переговоры основателя и инвестора о капитале, valuation, правах и milestones.

## Типовые роли
- founder
- investor
- investment committee representative

## Интересы сторон
- founder: капитал, контроль, скорость
- investor: return, downside protection, governance

## Возможные скрытые цели
- проверить runway/BATNA
- получить права
- понять реальную конкуренцию за сделку

## Базовая последовательность
- бизнес/рынок
- риски
- valuation
- доля
- governance
- milestones
- закрытие

## Критичные метрики
- Goal
- Control
- Trust

## Грубые ошибки
- ложные метрики
- скрытие существенного риска
- обсуждение только valuation

## Сильные ходы
- явные assumptions
- BATNA
- обсуждение прав и downside
- условный обмен

## Варианты
- angel
- VC seed
- strategic investor
- follow-on

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Юридические условия инвестиционной сделки в РФ требуют отдельной проверки.
