# Переговоры о зарплате

## Назначение
Тренировка обсуждения компенсации при найме или внутри компании.

## Типовые роли
- кандидат/сотрудник
- HR
- руководитель

## Интересы сторон
- игрок: достойная компенсация, развитие, формат
- работодатель: бюджет, внутренняя справедливость, удержание, ценность

## Возможные скрытые цели
- выяснить минимально приемлемый уровень
- понять силу BATNA
- обменять деньги на другие условия

## Базовая последовательность
- обоснование запроса
- якорь/диапазон
- возражение по бюджету
- критерии ценности
- обмен по пакету
- фиксация

## Критичные метрики
- Goal
- Control
- Trust

## Грубые ошибки
- ложный оффер как рычаг
- угроза без BATNA
- односторонняя критическая уступка

## Сильные ходы
- объективные критерии
- несколько параметров пакета
- условная уступка
- разумная BATNA

## Варианты
- найм
- ежегодный review
- promotion
- контроффер
- частичная компенсация через обучение/гибрид/бонус

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Не подменять профессиональную оценку личными симпатиями. Актуальные юридические требования проверять отдельно, если они существенны для сценария.
