# Расторжение договора

## Назначение
Переговоры о корректном завершении коммерческих отношений.

## Типовые роли
- заказчик
- исполнитель
- партнёры
- юристы/бизнес

## Интересы сторон
- минимизировать ущерб
- закрыть обязательства
- передать результаты
- сохранить/завершить отношения

## Возможные скрытые цели
- снизить компенсацию
- сохранить IP/данные
- получить переходный период

## Базовая последовательность
- основание
- факты
- обязательства
- деньги
- передача
- взаимные претензии
- фиксация

## Критичные метрики
- Goal
- Control
- Trust

## Грубые ошибки
- угрозы вне закона
- скрытие существенных обязательств
- двусмысленная фиксация

## Сильные ходы
- объективные критерии
- варианты перехода
- ясная фиксация

## Варианты
- мирное прекращение
- конфликтное
- частичное продолжение

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.
