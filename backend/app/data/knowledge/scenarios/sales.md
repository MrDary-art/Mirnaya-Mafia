# Продажи

## Назначение
Переговоры продавца с клиентом от discovery до коммерческого решения.

## Типовые роли
- sales manager
- клиент/ЛПР
- закупщик

## Интересы сторон
- продавец: ценная прибыльная сделка
- клиент: решить проблему при приемлемой цене/риске

## Возможные скрытые цели
- понять бюджет/срочность/полномочия
- защитить цену
- получить next step

## Базовая последовательность
- discovery
- problem/implication
- ценность
- возражение
- цена/условия
- конкурент
- закрытие

## Критичные метрики
- Goal
- Trust
- Control

## Грубые ошибки
- ложная срочность
- обман о продукте
- скидка без диагностики
- давление после явного отказа

## Сильные ходы
- SPIN
- ценностная аргументация
- условная уступка
- фиксация decision process

## Варианты
- B2B
- enterprise
- SMB
- продление
- возврат клиента
- недовольный клиент

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Не подменять профессиональную оценку личными симпатиями. Актуальные юридические требования проверять отдельно, если они существенны для сценария.
