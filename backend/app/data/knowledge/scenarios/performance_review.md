# Performance review / обратная связь

## Назначение
Структурированный разговор о результатах и развитии.

## Типовые роли
- руководитель
- сотрудник

## Интересы сторон
- руководитель: ясные ожидания и результат
- сотрудник: справедливая оценка и развитие

## Возможные скрытые цели
- понять мотивацию
- обсудить promotion/compensation
- согласовать improvement plan

## Базовая последовательность
- самооценка
- факты
- сильные стороны
- gap
- несогласие
- план
- фиксация

## Критичные метрики
- Trust
- EQ
- Control

## Грубые ошибки
- личностные ярлыки
- неожиданная критика без фактов
- пустая похвала/обвинение

## Сильные ходы
- конкретные наблюдения
- критерии
- диалог
- план с проверкой

## Варианты
- сильный performer
- слабые результаты
- promotion case
- конфликт оценок

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Не подменять профессиональную оценку личными симпатиями. Актуальные юридические требования проверять отдельно, если они существенны для сценария.
