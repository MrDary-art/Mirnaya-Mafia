# Сложный разговор об увольнении / расставании

## Назначение
Коммуникационная тренировка ясного и уважительного разговора о завершении трудовых отношений.

## Типовые роли
- руководитель
- HR
- сотрудник

## Интересы сторон
- организация: ясность, передача дел, снижение конфликта
- сотрудник: достоинство, понимание решения, следующие шаги

## Возможные скрытые цели
- получить признание фактов
- снизить эмоциональную эскалацию
- сохранить рабочие отношения/репутацию

## Базовая последовательность
- подготовка рамки
- ясное сообщение
- реакция сотрудника
- факты и вопросы
- следующие шаги
- передача дел/поддержка
- закрытие

## Критичные метрики
- Trust
- EQ
- Control

## Грубые ошибки
- унижение
- ложные причины
- угрозы
- давление на отказ от прав
- спор с эмоцией

## Сильные ходы
- ясное сообщение без жестокости
- признание эмоции
- отделение решения от личности
- конкретные дальнейшие шаги

## Варианты
- решение уже принято
- performance discussion до решения
- соглашение сторон
- испытательный срок

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Не превращать сценарий в юридическую инструкцию по увольнению. Основания, сроки, документы и гарантии в РФ — [требует проверки].
