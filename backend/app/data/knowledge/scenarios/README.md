# Сценарии

Файлы в этой папке задают **семейства** сценариев, а не фиксированные диалоги.

При генерации:
1. определить профессию/уровень;
2. загрузить соответствующий `professions/...md`;
3. загрузить сценарное семейство;
4. загрузить релевантные переговорные методы;
5. при необходимости выполнить web-актуализацию;
6. построить бриф, скрытые цели и дерево 6–8 шагов;
7. проверить сценарий на проходимость и этические ограничения.

Не копировать базовые дельты механически: option effects должны соответствовать конкретному контексту.
