# Повышение в должности

## Назначение
Переговоры о переходе на следующий уровень ответственности.

## Типовые роли
- сотрудник
- руководитель
- HR

## Интересы сторон
- сотрудник: рост/признание/компенсация
- руководитель: подтверждённая готовность и организационная потребность

## Возможные скрытые цели
- проверить удержание
- сформировать development plan
- выяснить реальные критерии

## Базовая последовательность
- запрос
- доказательства
- критерии уровня
- возражение
- пробелы
- план/решение

## Критичные метрики
- Goal
- Trust
- Control

## Грубые ошибки
- шантаж уходом без BATNA
- требование по стажу без результатов
- размытый отказ без критериев

## Сильные ходы
- конкретные достижения
- объективные критерии
- план с сроком/метриками

## Варианты
- готовое повышение
- отказ
- промежуточный план
- новая роль без бюджета

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Не подменять профессиональную оценку личными симпатиями. Актуальные юридические требования проверять отдельно, если они существенны для сценария.
