# Рабочий конфликт

## Назначение
Деэскалация и решение разногласий между коллегами/руководителем и сотрудником.

## Типовые роли
- коллеги
- руководитель и сотрудник
- две функции

## Интересы сторон
- результат, автономия, справедливость, статус, ресурсы

## Возможные скрытые цели
- сохранить лицо
- добиться признания ответственности
- защитить ресурсы

## Базовая последовательность
- факты
- восприятия
- интересы
- эмоциональная реакция
- варианты
- правила взаимодействия
- фиксация

## Критичные метрики
- Trust
- EQ
- Control

## Грубые ошибки
- переход на личности
- унижение
- приписывание мотивов как факта
- угроза

## Сильные ходы
- активное слушание
- отделение человека от проблемы
- конкретизация поведения
- совместный план

## Варианты
- два коллеги
- manager-report
- межфункциональный конфликт
- удалённая команда

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Не подменять профессиональную оценку личными симпатиями. Актуальные юридические требования проверять отдельно, если они существенны для сценария.
