# Собеседование / найм

## Назначение
Генерация интервью для любой профессии: HR-screening, профессиональное, техническое, ситуационное или финальное.

## Типовые роли
- кандидат
- HR/recruiter
- hiring manager
- профессиональный эксперт

## Интересы сторон
- кандидат: подходящая работа, условия, развитие, честная возможность показать компетенции
- работодатель: деловые качества, мотивация, риски найма, условия

## Возможные скрытые цели
- проверить несостыковки
- понять реальные ожидания
- проверить глубину заявленного опыта
- оценить способность учиться

## Базовая последовательность
- рамка и краткое знакомство
- мотивация/переход
- проверка ключевых компетенций
- 1–3 профессиональных кейса
- поведенческий пример
- вопросы кандидата
- условия/следующий шаг

## Критичные метрики
- Trust
- Goal
- EQ

## Грубые ошибки
- дискриминационный вопрос/решение
- унижение
- выдуманный опыт
- давление на личную жизнь
- оценка по нерелевантному признаку

## Сильные ходы
- конкретный пример
- уточняющий вопрос
- честное признание границы знания
- структурированное рассуждение
- содержательные вопросы о роли

## Варианты
- студент без опыта
- junior/middle/senior
- руководитель
- повторное интервью после отказа
- overqualified
- сильный кандидат со слабой коммуникацией

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Российские правовые требования найма и причины отказа при необходимости проверять по актуальным нормам. В тренажёре оценивать деловые качества.
