# Возврат / претензия клиента

## Назначение
Коммуникация по возврату товара/услуги или спору о качестве.

## Типовые роли
- клиент
- представитель компании

## Интересы сторон
- клиент: справедливое решение
- компания: законное/последовательное решение, доверие

## Возможные скрытые цели
- выяснить факты
- снизить напряжение
- предложить разрешённые варианты

## Базовая последовательность
- эмоция
- факты
- ожидание
- правила/ограничения
- варианты
- решение

## Критичные метрики
- Trust
- EQ
- Goal

## Грубые ошибки
- ложные юридические утверждения
- обесценивание клиента
- обещание невозможного

## Сильные ходы
- активное слушание
- проверка фактов
- варианты решения

## Варианты
- качество
- срок
- неполная услуга
- повторная претензия

## Правила генерации
- 6–8 шагов.
- На каждом шаге 3–4 ответа игрока.
- Дельты Trust/Goal/Control/EQ в диапазоне -6..+6.
- Каждый ответ должен менять либо состояние, либо информацию, либо отношения.
- Минимум три различимых финала.
- Сценарий должен быть проходимым.
- BATNA/ZOPA задавать только при наличии достаточных фактов.
- Реплики должны быть разговорными, без академической сухости.
- Оценка профессиональной части берётся из соответствующего файла `professions/`.
- Переговорная оценка берётся из `negotiations/`.

## Ограничения
Конкретные права потребителя и обязанности продавца в РФ — [требует проверки] перед публикацией.
