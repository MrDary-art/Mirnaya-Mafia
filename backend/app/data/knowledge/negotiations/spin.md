# SPIN

## Автор
Neil Rackham — *SPIN Selling* (1988).

## Суть
Методика вопросов для сложных продаж, особенно B2B.

## Четыре типа вопросов
- Situation — понять контекст.
- Problem — выявить проблему.
- Implication — исследовать последствия.
- Need-payoff — помочь сформулировать ценность решения.

## Правильное применение
SPIN — не жёсткий скрипт из четырёх вопросов подряд. Хороший разговор может пропускать этапы, возвращаться назад и использовать уже известную информацию.

## Ошибки
- слишком много Situation-вопросов;
- допрос вместо разговора;
- презентация продукта до диагностики;
- искусственные наводящие Implication-вопросы;
- попытка применять SPIN к любой конфликтной ситуации.

## Для оценки
Плюс — вопрос реально раскрывает проблему или ценность. Ноль — вопрос формально похож на SPIN, но ничего не добавляет. Минус — серия вопросов перегружает/раздражает собеседника.
