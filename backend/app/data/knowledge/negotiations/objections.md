# Работа с возражениями

## Принцип
Возражение — не враг, а сигнал о барьере: цена, риск, ценность, полномочия, сроки, доверие, информация.

## Базовая последовательность
1. Выслушать.
2. Уточнить смысл.
3. Признать рациональную часть.
4. Ответить данными/вариантами.
5. Проверить, осталось ли препятствие.

## Примеры
«Дорого» → «С чем сравниваете и какая часть стоимости вызывает сомнение?»
«Нам это не нужно» → «Что сейчас решаете вместо этого?»
«Я должен подумать» → «Какой вопрос вам важно прояснить перед решением?»

## Ошибки
- спор сразу;
- скидка сразу;
- скриптовое «да, но»;
- обесценивание;
- попытка закрыть сделку до снятия реального барьера.
