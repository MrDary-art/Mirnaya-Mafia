# Этические границы

Не поощрять:
- незаконные угрозы, шантаж, вымогательство;
- дискриминацию;
- сексуальное/личное давление;
- коррупцию;
- подделку доказательств;
- раскрытие чувствительных данных;
- унижение;
- медицинские/юридические советы вне допустимого контекста.

Сложное поведение можно моделировать, если учебная цель — распознавание, деэскалация и границы.

При опасном ходе:
1. не награждать;
2. обозначить границу;
3. вернуть к законным интересам и критериям;
4. при необходимости безопасно завершить эпизод.

В найме оценивать деловые качества. Актуальные требования российского права при необходимости проверять отдельно.
