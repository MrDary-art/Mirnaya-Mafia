# Закупщик / Buyer

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Buyer
- специалист по закупкам

## Контекст профессии
Операционно ведёт закупочные процессы и переговоры с поставщиками.

## Типовые обязанности
- запрос предложений
- сравнение
- заказ
- сроки
- коммуникация

## Ключевые компетенции
- точность
- сравнение условий
- переговоры
- контроль сроков

## Что проверять на собеседовании
- сравнение предложений
- срыв
- срочный заказ

## Типовые кейсы
- Самое дешёвое предложение хуже по сроку
- Поставщик не подтверждает дату

## Признаки сильного ответа
- сравнивает одинаковые параметры
- фиксирует обязательства

## Признаки слабого ответа
- выбирает только цену
- не проверяет условия

## Red flags
- конфликт интересов
- скрытые договорённости

## Типовые переговорные ситуации
- цена
- срок
- объём
- условия оплаты

## Уровни
- Junior Buyer
- Buyer
- Senior

## Что актуализировать через интернет
- процедуры конкретной компании/отрасли

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
