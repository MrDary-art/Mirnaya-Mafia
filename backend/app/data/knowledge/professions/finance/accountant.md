# Бухгалтер

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Accountant
- бухгалтер по участку
- главный бухгалтер — отдельный уровень

## Контекст профессии
Учёт хозяйственных операций, документы, закрытие периодов, контроль корректности данных и взаимодействие с внутренними/внешними сторонами.

## Типовые обязанности
- первичные документы
- учёт операций
- сверки
- закрытие
- контроль
- коммуникация с контрагентами

## Ключевые компетенции
- внимательность
- понимание участка
- контроль документов
- системность
- эскалация ошибок

## Что проверять на собеседовании
- реальный участок учёта
- ошибка/расхождение
- закрытие периода
- взаимодействие с контрагентом

## Типовые кейсы
- Документ пришёл после закрытия
- Сверка не сходится
- Коллега просит провести операцию без достаточных документов

## Признаки сильного ответа
- не проводит сомнительное действие автоматически
- фиксирует источник расхождения
- эскалирует по процедуре

## Признаки слабого ответа
- «так всегда делали» без проверки
- игнорирует контрольный след

## Red flags
- готовность подделать/исказить учёт
- скрыть существенную ошибку

## Типовые переговорные ситуации
- сроки документов
- приоритет закрытия
- конфликт с бизнесом из-за процедур

## Уровни
- Бухгалтер участка
- Ведущий
- Зам./главный бухгалтер

## Что актуализировать через интернет
- действующие правила бухучёта/налоговые нормы РФ [требует проверки]
- конкретная учётная система

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
