# Backend-разработчик

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Backend Developer
- Python/Java/Go/.NET backend engineer

## Контекст профессии
Разработка серверной логики, API, интеграций, работы с данными и надёжностью сервисов.

## Типовые обязанности
- проектирование API
- бизнес-логика
- работа с БД
- интеграции
- тестирование
- наблюдаемость
- code review
- разбор инцидентов

## Ключевые компетенции
- язык/экосистема
- HTTP/API
- SQL/данные
- тестирование
- архитектурные trade-offs
- надёжность
- безопасность на базовом уровне
- командная работа

## Что проверять на собеседовании
- реальные проекты
- ошибка/инцидент
- проектирование API
- SQL/транзакции
- тесты
- масштабирование по уровню
- code review

## Типовые кейсы
- Спроектировать API бронирования
- Дубликаты платежей при retry
- Медленный SQL-запрос
- Нужно изменить контракт без поломки клиентов

## Признаки сильного ответа
- объясняет причинно-следственные связи
- называет trade-offs
- признаёт границы знания
- приводит реальные примеры
- думает о тестах/ошибках/идемпотентности

## Признаки слабого ответа
- перечисляет термины без понимания
- магические технологии «потому что модно»
- не учитывает ошибки/данные
- не может объяснить свой вклад

## Red flags
- выдуманный опыт
- игнорирование безопасности/данных
- обвинение команды во всех ошибках
- невозможность объяснить собственный код

## Типовые переговорные ситуации
- оценка сроков
- scope
- архитектурные споры
- техдолг vs фича
- зарплата/оффер

## Уровни
- Junior: базовые конструкции, HTTP, SQL, тесты
- Middle: самостоятельные решения, интеграции, эксплуатация
- Senior: системные trade-offs, надёжность, mentoring
- Lead: техническое направление и коммуникация

## Что актуализировать через интернет
- актуальный стек вакансии
- версии фреймворков/облаков
- конкретная архитектура компании
- актуальные требования вакансий РФ

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
