# Data Scientist / ML

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Data Scientist
- ML Engineer — частично

## Контекст профессии
Построение и оценка моделей, эксперименты, работа с данными и внедрением.

## Типовые обязанности
- формулировка ML-задачи
- features/data
- model evaluation
- experiments
- deployment collaboration
- monitoring

## Ключевые компетенции
- статистика/ML
- валидация
- data leakage
- метрики
- business objective
- эксперименты

## Что проверять на собеседовании
- выбор метрики
- leakage
- class imbalance
- offline vs online
- проект end-to-end

## Типовые кейсы
- Высокая accuracy при редком событии
- Модель деградировала после релиза
- Признак доступен только после события

## Признаки сильного ответа
- связывает metric с business cost
- проверяет leakage
- понимает validation

## Признаки слабого ответа
- гонится за моделью без baseline
- не знает источник данных
- говорит только про алгоритмы

## Red flags
- подгонка/скрытие результатов
- игнорирование рисков данных

## Типовые переговорные ситуации
- ресурсы на эксперимент
- ML vs rule-based
- срок исследования

## Уровни
- Junior DS
- Middle
- Senior
- Lead

## Что актуализировать через интернет
- актуальный ML stack/LLM требования вакансии
- конкретные compliance/data ограничения

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
