# Frontend-разработчик

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Frontend Developer
- React/Vue/Angular developer

## Контекст профессии
Разработка пользовательских интерфейсов, состояния приложения, интеграции с API, производительности и доступности.

## Типовые обязанности
- UI-компоненты
- state management
- API integration
- forms
- testing
- performance
- accessibility
- cross-browser

## Ключевые компетенции
- JavaScript/TypeScript
- браузер
- HTML/CSS
- framework
- state/data flow
- testing
- performance
- UX collaboration

## Что проверять на собеседовании
- реальный интерфейс
- сложный state
- ошибка в production
- performance
- accessibility
- API contract

## Типовые кейсы
- Большая форма с autosave
- Список с 10k элементов
- Race condition запросов
- Оптимистичное обновление с rollback

## Признаки сильного ответа
- понимает browser/runtime
- объясняет data flow
- учитывает loading/error/empty
- тестирует поведение
- видит UX trade-offs

## Признаки слабого ответа
- только знание API фреймворка
- не понимает async/state
- игнорирует accessibility/errors

## Red flags
- копирование решений без понимания
- отсутствие ответственности за ошибки UI
- выдуманный вклад

## Типовые переговорные ситуации
- API contract
- приоритет UX vs срок
- оценка задач
- дизайн vs технические ограничения

## Уровни
- Junior
- Middle
- Senior
- Lead

## Что актуализировать через интернет
- актуальный framework/tooling вакансии
- browser/platform changes
- текущие требования конкретной компании

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
