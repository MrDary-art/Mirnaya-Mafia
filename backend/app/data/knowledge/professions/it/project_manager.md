# Project Manager

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- PM
- руководитель проекта

## Контекст профессии
Управление scope, сроком, риском, зависимостями, коммуникацией и ожиданиями stakeholders.

## Типовые обязанности
- планирование
- risks
- dependencies
- status
- change management
- stakeholders
- delivery

## Ключевые компетенции
- структура
- risk management
- negotiation
- estimation awareness
- communication
- escalation

## Что проверять на собеседовании
- сорванный срок
- scope change
- конфликт ресурсов
- риск
- статус заказчику

## Типовые кейсы
- Проект отстаёт на месяц
- Заказчик добавляет scope без срока
- Ключевой специалист недоступен

## Признаки сильного ответа
- ранняя прозрачность
- варианты trade-off
- конкретный recovery plan

## Признаки слабого ответа
- скрытие проблемы
- обещание срока без команды
- микроменеджмент вместо управления

## Red flags
- подмена статуса оптимизмом
- перекладывание ответственности

## Типовые переговорные ситуации
- сроки
- scope
- ресурсы
- подрядчики
- заказчик

## Уровни
- Junior PM
- PM
- Senior
- Program/Portfolio

## Что актуализировать через интернет
- методология/инструменты конкретной компании
- регуляторные требования проекта

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
