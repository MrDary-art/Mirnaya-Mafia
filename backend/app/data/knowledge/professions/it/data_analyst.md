# Data Analyst

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- аналитик данных
- BI Analyst

## Контекст профессии
Анализ данных, метрики, отчётность, эксперименты и помощь в принятии решений.

## Типовые обязанности
- SQL
- дашборды
- анализ
- метрики
- качество данных
- коммуникация выводов

## Ключевые компетенции
- SQL
- статистика на уровне роли
- метрики
- визуализация
- business sense
- data quality

## Что проверять на собеседовании
- пример решения по данным
- ошибка метрики
- SQL
- эксперимент
- коммуникация неопределённости

## Типовые кейсы
- Метрика выросла, бизнес упал
- Два источника дают разные числа
- A/B тест неоднозначен

## Признаки сильного ответа
- проверяет качество данных
- говорит о причинности осторожно
- связывает вывод с решением

## Признаки слабого ответа
- приравнивает корреляцию к причинности
- нет проверки данных
- делает вывод из одного графика

## Red flags
- манипуляция графиком/метрикой
- скрытие неопределённости

## Типовые переговорные ситуации
- выбор KPI
- ресурсы на аналитику
- спор о результатах эксперимента

## Уровни
- Junior
- Middle
- Senior/Lead

## Что актуализировать через интернет
- актуальный BI/data stack вакансии
- доменные метрики компании

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
