# Product Manager

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Product Manager
- менеджер продукта

## Контекст профессии
Определение проблемы/ценности, приоритетов, метрик и координация развития продукта.

## Типовые обязанности
- discovery
- prioritization
- roadmap
- metrics
- stakeholders
- experiments
- go-to-market collaboration

## Ключевые компетенции
- problem framing
- product sense
- metrics
- prioritization
- research
- stakeholder negotiation

## Что проверять на собеседовании
- провальный запуск
- приоритет
- метрика
- конфликт с разработкой
- исследование

## Типовые кейсы
- CEO требует фичу без данных
- Метрика растёт, retention падает
- Две аудитории конфликтуют

## Признаки сильного ответа
- формулирует problem before solution
- явно называет trade-off
- использует evidence

## Признаки слабого ответа
- список фреймворков без решений
- roadmap как список хотелок
- vanity metrics

## Red flags
- манипулирование данными
- обещание невозможного команде/бизнесу

## Типовые переговорные ситуации
- roadmap
- ресурсы
- scope
- приоритет stakeholders

## Уровни
- Associate/Junior
- PM
- Senior
- Lead/Head

## Что актуализировать через интернет
- рынок/конкуренты конкретного продукта
- актуальные продуктовые метрики домена

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
