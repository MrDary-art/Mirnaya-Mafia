# PR / корпоративные коммуникации

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- PR Manager
- Communications Manager

## Контекст профессии
Управляет внешними/внутренними сообщениями, репутационными ситуациями и взаимодействием со СМИ/аудиториями.

## Типовые обязанности
- media relations
- message development
- crisis communication
- internal comms
- reputation

## Ключевые компетенции
- ясность сообщения
- risk awareness
- stakeholder communication
- fact checking
- crisis discipline

## Что проверять на собеседовании
- кризис
- неудобный вопрос
- ошибка компании
- внутренняя коммуникация

## Типовые кейсы
- Появилась негативная публикация
- Факт ещё не проверен
- Руководитель хочет скрыть известную проблему

## Признаки сильного ответа
- отделяет подтверждённые факты
- не спекулирует
- готовит понятное сообщение

## Признаки слабого ответа
- реакция до проверки
- агрессия к критикам

## Red flags
- ложное заявление
- сокрытие существенного риска как рекомендуемая стратегия

## Типовые переговорные ситуации
- позиция компании
- срок публикации
- конфликт transparency vs risk

## Уровни
- Specialist
- Manager
- Head

## Что актуализировать через интернет
- актуальный медиаконтекст и регулирование

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
