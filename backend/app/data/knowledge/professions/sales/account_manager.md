# Account Manager / Key Account Manager

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Account Manager
- KAM
- менеджер по работе с ключевыми клиентами

## Контекст профессии
Развивает существующих клиентов, удерживает отношения, решает проблемы и расширяет сотрудничество.

## Типовые обязанности
- relationship management
- renewal
- upsell
- issue coordination
- commercial negotiation
- stakeholder mapping

## Ключевые компетенции
- доверие
- переговоры
- структура аккаунта
- коммерческое мышление
- эскалация
- долгосрочность

## Что проверять на собеседовании
- удержание недовольного клиента
- продление
- эскалация
- работа с несколькими stakeholders

## Типовые кейсы
- Крупный клиент угрожает уйти
- Просит нестандартную скидку
- Сервис подвёл клиента

## Признаки сильного ответа
- признаёт проблему без пустых обещаний
- предлагает recovery plan
- понимает ценность аккаунта и границы

## Признаки слабого ответа
- защищается вместо решения
- обещает то, что не контролирует
- даёт скидки без обмена

## Red flags
- скрывать реальную проблему
- обвинять клиента
- фиктивные обещания

## Типовые переговорные ситуации
- продление
- SLA
- компенсация
- upsell
- retention

## Уровни
- Account Manager
- Senior/KAM
- Strategic Account

## Что актуализировать через интернет
- актуальные коммерческие условия/продукт
- рынок конкретного аккаунта

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
