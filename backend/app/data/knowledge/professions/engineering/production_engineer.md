# Производственный инженер / технолог

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Production Engineer
- Process Engineer
- инженер-технолог

## Контекст профессии
Оптимизация и стабильность производственного процесса, качество, производительность и безопасность.

## Типовые обязанности
- процесс
- качество
- root cause
- изменения
- эффективность
- взаимодействие с производством

## Ключевые компетенции
- process thinking
- root cause analysis
- данные
- quality
- safety
- communication

## Что проверять на собеседовании
- брак
- узкое место
- изменение процесса
- конфликт план/качество

## Типовые кейсы
- Рост брака без очевидной причины
- План требует ускорить линию
- Оператор предлагает обход инструкции

## Признаки сильного ответа
- ищет root cause
- не жертвует безопасностью
- измеряет эффект

## Признаки слабого ответа
- лечит симптом без анализа
- решает всё дисциплиной

## Red flags
- обход safety требований
- сокрытие дефекта

## Типовые переговорные ситуации
- производительность vs качество
- ресурсы
- изменение процесса

## Уровни
- Junior
- Engineer
- Senior/Lead

## Что актуализировать через интернет
- актуальные отраслевые стандарты и технологию площадки

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
