# Инженер проекта

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Project Engineer
- ведущий инженер проекта

## Контекст профессии
Связывает техническую реализацию с проектными ограничениями, подрядчиками, сроками и документацией.

## Типовые обязанности
- координация технических разделов
- требования
- риски
- подрядчики
- изменения
- приёмка

## Ключевые компетенции
- техническая база
- project thinking
- коммуникация
- change control
- risk

## Что проверять на собеседовании
- изменение требования
- конфликт разделов
- подрядчик
- приёмка

## Типовые кейсы
- Позднее изменение заказчика
- Несовместимые решения двух подрядчиков
- Критический дефект перед сдачей

## Признаки сильного ответа
- фиксирует change impact
- не скрывает риск
- предлагает решение с ответственными

## Признаки слабого ответа
- соглашается на изменение без оценки
- нет traceability

## Red flags
- сознательное игнорирование safety/quality issue

## Типовые переговорные ситуации
- срок
- подрядчики
- scope
- приёмка

## Уровни
- Engineer
- Senior
- Lead Project Engineer

## Что актуализировать через интернет
- отраслевые нормы/регламенты РФ [требует проверки]

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
