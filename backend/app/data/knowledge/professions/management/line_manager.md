# Линейный руководитель

## Назначение
Профиль для генерации собеседований, переговорных тренировок и оценки ответов.

## Варианты названия / близкие роли
- Team Lead
- руководитель группы
- line manager

## Контекст профессии
Управляет результатом команды, обратной связью, нагрузкой, развитием и конфликтами.

## Типовые обязанности
- goal setting
- delegation
- feedback
- performance
- conflict
- resource management

## Ключевые компетенции
- ясность ожиданий
- обратная связь
- слушание
- ответственность
- приоритизация
- деэскалация

## Что проверять на собеседовании
- сложный feedback
- срыв срока
- перегрузка
- повышение
- конфликт

## Типовые кейсы
- Сотрудник не согласен с оценкой
- Два человека конфликтуют
- Ключевой сотрудник перегружен

## Признаки сильного ответа
- конкретные факты/ожидания
- разделяет человека и поведение
- фиксирует следующий шаг

## Признаки слабого ответа
- личностные ярлыки
- неясные требования
- микроменеджмент вместо договорённости

## Red flags
- унижение/угрозы
- дискриминация
- манипуляция увольнением

## Типовые переговорные ситуации
- ресурсы
- сроки
- повышение
- зарплата
- нагрузка

## Уровни
- First-time manager
- Manager
- Senior Manager

## Что актуализировать через интернет
- актуальные политики компании
- трудовые нормы РФ [требует проверки]

## Ограничения
Не превращать интервью в викторину по редким фактам. Оценивать релевантный опыт, мышление, доказательства и коммуникацию. Конкретные требования конкретной вакансии проверять по описанию вакансии и актуальному контексту.
