# Реализованные функции (v1.1)

## ✅ Что было добавлено

### 1. Режим хаоса (полная реализация)
- **5 типов помех** с влиянием на метрики:
  - `interruption` — оппонент перебивает
  - `phone_call` — звонок телефона
  - `visitor` — посетитель заходит в комнату
  - `connection_loss` — связь прерывается
  - `topic_change` — оппонент меняет тему
- **Частота событий** зависит от сложности:
  - Лёгкий: 5%
  - Средний: 10%
  - Сложный: 15%
  - Жёсткий: 20%
- **3 варианта ответа** на каждое событие с разными дельтами
- **API endpoint** `/sessions/{id}/chaos-response` для обработки выбора
- **История событий** сохраняется в отчёте

## 📋 Как использовать режим хаоса

### В настройках сессии:
```json
{
  "chaos": true,
  "difficulty": "сложный"
}
```

### Поток работы:
1. Игрок делает выбор варианта
2. Если `chaos=true` и выпадает событие → возвращается `chaos_event`
3. Фронтенд показывает модальное окно с событием и 3 вариантами ответа
4. Игрок выбирает ответ → `POST /chaos-response`
5. Применяются дельты, игра продолжается

   - Ключи GigaChat/Ollama не подключены
   - Батчинг анализа 3-5 реплик — частично

3. **Отчёт**:
   - Визуализация ZOPA — нет
   - Финальный LLM-анализ — rule-based только

4. **Деплой**:
   - Публичный URL — нет
   - HTTPS, certbot — нет

5. **Контент**:
   - Сценарии — только 3 (нужно 5-10)
