# «Контракт на кону»

Готовый кейс Совета решений: четыре игрока, 15–20 минут и разбор. В форме назначения выберите «Контракт на кону · готовая игра». Организатор может играть одну из четырёх ролей; отдельный ведущий необязателен. Редактор собственных сценариев остаётся отдельным вариантом.

## Ход партии

1. Прочитайте личную роль и подтвердите готовность. Организатор начинает встречу в назначенное время.
2. Первые предложения: у каждого своя цель, интерес, полномочия и закрытые факты.
3. После согласия всех четырёх откроется вторая часть личного досье.
4. Следующий общий переход открывает событие: ускорение своими силами дорожает на 5 000 ₽. Цена партнёра остаётся прежней.
5. Перейдите к соглашению, сохраните способ исполнения, объём, сроки, расходы, предоплату и ответственного. Любое редактирование снимает прежние подписи.
6. Все четыре участника подтверждают одну версию. Сервер проверяет выполнимость и показывает последствия, а также сохранённые личные интересы и уступки.

Время этапов — ориентир. Переходы добровольные и требуют согласия всех четырёх игроков. Действия из комнаты и экрана звонка используют одно серверное состояние. Личные чаты и заметки сохраняют существующие ограничения доступа. Играющий организатор не получает чужие карточки через модераторскую панель.

## Проверка

- Открытое демо: `/demo/council`. Четыре QR-кода, самостоятельное переключение этапов для демонстрации, две части досье и проверка соглашения на сервере.
- В демонстрации роли не синхронизированы между устройствами: вторую вводную участник открывает по команде общего стола. В полной встрече этап синхронизируется сервером.
- Пример экономной сделки после события: своими силами, 40%, 14 дней, остаток на 30-й день, 25 000 ₽, предоплата 30%, указан ответственный.
- Альтернатива: партнёр, 50%, 12 дней, остаток на 30-й день, 35 000 ₽, предоплата 40%. Клиент и производство сохраняют личные интересы, проект и финансы уступают резерв.
- `cd backend && python -m pytest tests/test_council_social.py tests/test_council.py tests/test_council_authoring.py tests/test_council_reservations_runtime.py tests/test_council_companies.py tests/test_council_operations.py -q`
- `cd frontend && npm run build`

Правила и финальный исход находятся в `backend/app/engine/council_social.py`. Данные этапов сохраняются в существующем `CouncilMeeting.configuration`; миграция не требуется. Старые встречи с режимом `classic` сохраняют прежнюю проверку условий.

Игровые последствия не требуют ИИ и обработки звука. Если включён микрофон, существующий механизм записывает речь для отдельного личного разбора. Этот разбор требует настроенных Whisper и ИИ; он не подменяет проверку числовых условий соглашения.
