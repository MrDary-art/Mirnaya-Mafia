# Фотографии команды

Положите в эту папку четыре фотографии с именами:

- `andrey.jpg` — Суховский Андрей
- `darya.jpg` — Полякова Дарья
- `veronika.jpg` — Федотова Вероника
- `anzhelika.jpg` — Федотова Анжелика

Также подходят настоящие файлы PNG, WebP, JPEG и AVIF с тем же именем и соответствующим расширением. Простое переименование расширения не меняет формат фотографии.

Фотографии автоматически заменяют одноимённые SVG-иконки на карточках команды. SVG можно оставить: это запасная картинка, если фото отсутствует или повреждено. Если есть несколько фото одного человека, порядок выбора: jpg, jpeg, png, webp, avif.

Лучше использовать квадратный портрет с лицом по центру: на сайте он обрезается по кругу.

При локальном запуске Vite изменения подхватываются автоматически; если фото не обновилось, обновите страницу. Для публикации снова выполните `npm.cmd run build` и загрузите обновлённую сборку.
