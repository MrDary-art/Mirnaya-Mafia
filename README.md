# Арена переговоров

Учебное приложение для отработки переговоров: сценарные миссии с разбором, авторский путь из 10 глав, теория, свободный ИИ-диалог и парная практика. Основной цикл: **ситуация → решение → последствия → отчёт → повтор**. Код приложения — Node.js, TypeScript и React в npm workspaces. Сценарные миссии, учебный путь и теория работают локально после установки; ИИ и распознавание речи требуют отдельно запущенных провайдеров.

## Быстрый запуск

Требуются **Node.js 24.x** и npm 11.x. Из корня проекта:

```sh
npm ci
npm run build
npm start
```

Откройте <http://127.0.0.1:3000>. Для разработки: `npm run dev` (интерфейс — порт 5173, API — 3000). Проверка: `npm run check`.

Локальные аккаунты:

| Логин | Пароль | Поведение |
| --- | --- | --- |
| `demo@example.com` | `1234` | Данные и прогресс очищаются при каждом запуске сервера. |
| `pinggos` | `4321` | Прогресс сохраняется между запусками. |

SQLite хранится в `data/arena-v2.db`. Путь можно изменить через `ARENA_DB_PATH`; папку `data/` при обновлении проекта удалять нельзя. По умолчанию сервер слушает только `127.0.0.1`; адрес и порт задаются переменными `HOST` и `PORT`. Изменения схемы применяются при запуске через `schema_migrations`; существующую базу переписывать вручную не требуется. Перед обновлением рабочей установки всё же сделайте копию базы.

## Возможности

- **Миссии.** 15 перенесённых сценариев с подготовкой, выбором действий, четырьмя серверными метриками (`trust`, `goal`, `control`, `eq`), итогами, упражнениями и повтором. В некоторых шагах есть включаемые подсказки «тренера-призрака». Можно включить скрытую цель (в размеченных сценариях), событие хаоса и ограничение времени на ход 30/60 секунд. Отчёт показывает график метрик, размеченные автором стили TKI, скрытую цель, реакции на событие и ошибки. Клиент не может назначить себе метрики или XP. Миссии не обращаются к ИИ и не требуют сети.
- **Путь развития.** 10 глав, 60 уровней, 240 авторских упражнений из прежнего проекта. Варианты перемешиваются на каждую попытку; качество ответа не видно до выбора. Сервер последовательно открывает уровни, сохраняет лучшую оценку и начисляет 10 XP один раз за уровень. После уровня доступен разбор всех ответов; после главы — итог с качеством, освоенным приёмом и ошибками последних попыток.
- **Теория.** Авторские уроки BATNA и ZOPA с разделами, источниками и практикой. За полный урок начисляется 15 XP один раз.
- **Дерево навыков.** Перенесены направления HR и Sales: 27 узлов, короткие задания и финальные сцены, связанные с настоящими офлайн-миссиями. Текстовые ответы проверяются по ключевым приёмам; интерфейс прямо указывает на ограничение такой проверки.
- **ИИ-диалог.** Анкета задаёт роли, проблему, цель, характер, уровень, пять ступеней сложности и рабочий контекст; настройки можно сохранить как пресет аккаунта. Переговоры начинаются первой репликой собеседника, собеседование использует план из 10 вопросов по должности. После каждой пользовательской реплики сервер записывает ориентировочные метрики и комментарий; завершённый разговор получает отчёт. Оценка основана на текстовых признаках и **не подтверждает** фактическую правильность или реальное согласие. XP за этот режим пока не начисляется. Сначала используются настроенные GigaChat/Ollama, при недоступности — другой настроенный провайдер, затем локальный шаблонный ответ. Внешние модели требуют отдельного запуска.
- **Голос.** При настроенном локальном Whisper-сервере запись с микрофона преобразуется в текст. Озвучивание каждого ответа можно включить даже в текстовом чате; сейчас оно использует голосовой движок браузера, поэтому зависит от доступных в системе голосов.
- **Люди и комнаты.** Поиск аккаунтов, заявки в друзья, личные сообщения, карточка прогресса друга только для друзей и входящие приглашения. Другу можно отправить приглашение на немедленную встречу или выбрать свободный интервал по 30 минут на ближайшую неделю (МСК); перед началом оба отмечают готовность. Комната поддерживает чат, WebRTC-звонок, локальную запись своего микрофона для скачивания и экспорт текстового протокола. После встречи участники отдельно отмечают, договорились ли они; общий итог показывает совпадение или расхождение оценок, но не оценивает качество переговоров. Комнату можно отменить; без принятия она истекает через сутки после создания или назначенного времени. Есть отдельная управляемая демонстрация без сохранения и формат двух ИИ-собеседований с общим протоколом после завершения.
- **Награды.** Шесть рангов с требованиями по XP и реальным результатам, постоянные достижения с датами получения, звёзды за качество и сложность миссий, новую роль и сценарий, сниженные награды за повторы. Магазин включает аватары, рамки и темы профиля с условиями разблокировки и историей операций. Отдельное ежедневное испытание выбирает офлайн-миссию по московской дате и выдаёт 2 звезды один раз за день. Покупки и экипировка сохраняются на сервере. Для миссий, завершённых до введения новой системы наград, достижения пересчитываются, но бонусы за качество задним числом не начисляются.
- **История и профиль.** Общая история миссий, учебных попыток, ИИ-диалогов и комнат с фильтрами и продолжением незавершённых занятий. Личный профиль показывает дату регистрации, роли, разные сценарии, последнюю метрику и учебную статистику. Имя интерфейса остаётся локальной настройкой; публичная анкета пока не реализована.
- **Обзор владельца.** Аккаунт владельца видит количество пользователей, миссий и комнат и их последние статусы. Это обзор без изменения серверной конфигурации.
- **Работа над ошибками.** Из завершённых миссий собираются ходы, снизившие метрики; пользователь пишет новую реплику, сохраняет её и сравнивает с авторской альтернативой. Автоматической оценки свободного текста пока нет.
- **Аккаунт и оформление.** Регистрация, вход, серверная сессия, CSRF-защита, подтверждение выхода, персонализация в браузере и единое оформление Solana × Solflare. Локальный demo-аккаунт сбрасывается целиком; `pinggos` остаётся постоянным.

## Подключение ИИ и голоса

Переменные окружения задаются **на сервере**, ключи не добавляются в исходники или клиентскую сборку. Для Ollama установите и запустите Ollama, загрузите выбранную модель и запустите проект с:

```text
ARENA_AI_PROVIDER=ollama
ARENA_OLLAMA_MODEL=<имя установленной модели>
ARENA_OLLAMA_URL=http://127.0.0.1:11434
```

В PowerShell переменные задаются перед запуском, например: `$env:ARENA_AI_PROVIDER='ollama'; $env:ARENA_OLLAMA_MODEL='имя-модели'; npm start`. Они действуют только в текущем окне терминала.

Для GigaChat задайте `ARENA_AI_PROVIDER=gigachat`, `GIGACHAT_AUTH_KEY=<ключ авторизации>` и при необходимости `GIGACHAT_MODEL` и `GIGACHAT_SCOPE`. Можно одновременно задать переменные Ollama: если первый сервис недоступен, сервер попробует второй. Если оба недоступны или не настроены, используется ограниченный локальный шаблонный ответ. Сервер получает временный токен по OAuth и держит ключ только в своём окружении. Адреса API следуют [документации GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-token) и [методу генерации ответа](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/post-chat). Ollama используется через [официальный `/api/chat`](https://docs.ollama.com/api/chat). Для GigaChat может потребоваться установка доверенных сертификатов в системе; проверка TLS в приложении не отключается.

Для голосового ввода запустите локальный [сервер whisper.cpp](https://github.com/ggml-org/whisper.cpp/blob/master/examples/server/README.md) с русской моделью и задайте `ARENA_WHISPER_URL=http://127.0.0.1:8080`. Приложение отправляет WAV на `/inference`. Доступ к микрофону в браузере требует `localhost` или HTTPS; для WebRTC между сетями настройте `ARENA_ICE_SERVERS` как JSON-массив серверов STUN/TURN, например `[ {"urls":"turn:example.org:3478","username":"...","credential":"..."} ]`. Для удалённого сайта также нужны HTTPS, надёжный TURN и отдельная проверка сетевой конфигурации.

## Структура

| Путь | Назначение |
| --- | --- |
| `apps/server/` | Express API, SQLite, доступ, ИИ, комнаты и статический сервер |
| `apps/web/` | React-интерфейс и локальные графические ресурсы |
| `packages/contracts/` | Общие схемы входных данных API |
| `packages/domain/` | Движок сценариев, метрики и отчёты |
| `packages/content/` | Сценарии, учебный путь и теория |
| `tests/` | Проверки сценариев, API, прав доступа и наград |
| `docs/migration-audit.md` | Происхождение контента и оставшиеся задачи переноса |

Графические источники и лицензии указаны в [описании фонов](apps/web/public/backgrounds/README.md). Исходники прежнего Python-приложения доступны в истории Git; новый runtime не зависит от Python. Перенос старой SQLite-базы **не выполняется автоматически**: её нельзя подменять текущей базой без отдельного скрипта с резервной копией и сверкой данных.

## Что ещё не перенесено

Публичная анкета и приватность профиля, отметки прочтения сообщений и уведомлений, серверное хранение аудиозаписей, содержательный автоматический разбор человеческого разговора, командный рейтинг, автоматический вердикт парного ИИ-собеседования, глубокая проверка свободных ответов, импорт старых аккаунтов, локальный Piper TTS, PostgreSQL и почтовые сценарии для интернет-версии. Подробности — в [карте переноса](docs/migration-audit.md). `ARENA_MODE=site` не следует считать готовым публичным развёртыванием до проверки сетевого режима, HTTPS и TURN.
