# Арена переговоров

**Работающий сайт: [24projects.ru](https://24projects.ru/)**
**Репозиторий: [MrDary-art/Mirnaya-Mafia](https://github.com/MrDary-art/Mirnaya-Mafia)**

Арена переговоров — веб-платформа для подготовки к сложным разговорам, практики и разбора результатов. Пользователь изучает теорию, проходит сценарии, пробует стратегии, тренируется с ИИ или другим человеком и возвращается к сохранённым отчётам. Для организаций предусмотрено отдельное пространство с сотрудниками, назначениями, встречами и аналитикой команды.

## 1. Сайт и возможности

### Как начать

1. Откройте [сайт](https://24projects.ru/) и нажмите «Войти».
2. Выберите личную практику или работу с компанией. Войдите в существующий аккаунт либо зарегистрируйтесь, если регистрация разрешена владельцем установки.
3. Для знакомства с личной Ареной начните с теории и готового сценария. Для корпоративной работы создайте компанию или присоединитесь по приглашению.
4. Завершите практику и откройте отчёт: он показывает результат, применённые приёмы и направления для следующей тренировки.

Отдельная публичная посадочная страница `/business#contact` удалена. Адрес `/business` открывает корпоративный вход или рабочий кабинет. Корпоративные пространства доступны после авторизации по адресам вида `/business/<companyId>/...`.

### Личная Арена

| Раздел | Возможности |
| --- | --- |
| Теория | Последовательное изучение подготовки, интересов сторон, аргументации и других приёмов; задания и сохранение прогресса. |
| Тренажёр | Упражнения по навыкам и открытие следующих уровней по условиям программы. |
| Готовые сценарии | Выбор реплик, реакция собеседника, изменения показателей, разные ветки и финалы. Работают без внешнего ИИ. |
| Практика с ИИ | Подготовка своей ситуации, ролей и цели; текстовый или голосовой разговор и разбор. Требуется настроенный провайдер ИИ. |
| Онлайн 1×1 | Создание встречи или вход по приглашению, выбор ролей, проверка устройств, разговор и результаты. При неподтверждённом микрофоне доступна готовность в текстовом режиме. |
| Трудоустройство с ИИ 1×1 | Два кандидата проходят отдельные интервью на одинаковых условиях; результаты связаны с общей комнатой. |
| Аналитика | Показатели завершённых практик, динамика результатов и направления развития. |
| Потенциальный двойник | Сравнение текущего результата с лучшими навыками, уже показанными в собственных практиках. |
| Истории и сериалы | Интерактивные сюжеты с выбором решений и последствиями. |
| Сообщество | Посты и истории, комментарии, отметки, закладки и подборки. |
| Профиль | Отчёты, записи на встречи, достижения и личные настройки. |

Канонические показатели: доверие (`trust`), достижение цели (`goal`), контроль разговора (`control`) и эмоциональная устойчивость в ситуации (`eq`). Сервер хранит состояние и рассчитывает результат; браузер отображает его. Оценки относятся к учебной практике, не являются психологическим диагнозом и не гарантируют успеха в реальных переговорах.

Отчёт о прогрессе открывается от 10 подходящих завершённых отчётов, потенциальный двойник — от 15. Незавершённые практики и результаты, ещё закрытые условиями корпоративного задания, не дают такого доступа автоматически.

### Арена бизнеса

[Корпоративный вход](https://24projects.ru/business/login). Выбор доступных компаний: `/business/workspaces`.

- Владелец управляет компанией, сотрудниками, подразделениями, назначениями и доступными настройками.
- Сотрудник видит свои задания, материалы, встречи и результаты в пределах выданных прав.
- Обучение включает программы, сценарии, сроки, попытки прохождения, результаты и сертификаты.
- Рабочие ситуации и встречи связывают участников, подготовку, обсуждение и договорённости.
- Совет решений поддерживает обсуждение с ролями, предложениями и согласованием решения.
- Аналитика и рейтинги команды помогают выбирать следующую практику.
- Сообщество компании объединяет публикации и общение команды.

Права проверяются сервером по роли, членству и области доступа. Администратор платформы и владелец компании — разные роли.

### Администрирование и модерация

[Административный интерфейс](https://24projects.ru/admin) предназначен для управления пользователями и компаниями, обращениями, настройками ИИ, почты и речи. Учётные данные задаёт владелец установки; они не публикуются в репозитории.

Модератор работает только в пределах назначенных полномочий. Назначение модератором Совета решений не предоставляет автоматически права администратора платформы или владельца компании.

### Голос и видео

В практике с ИИ используется API распознавания браузера. Реплика отправляется после нажатия «Отправить»; пауза и остановка распознавания сами по себе не должны отправлять ответ. Возможность зависит от браузера и доступности его службы. Текстовый ввод остаётся доступен.

Для видеосвязи нужны HTTPS, разрешения устройств и доступное сетевое соединение. Между разными сетями может потребоваться TURN. Для обработки записей встреч предусмотрены локальный Whisper и внешний worker. Настройки Whisper не управляют API распознавания браузера в личной практике с ИИ.

## 3. Как скачать

Для использования сайта ничего скачивать не нужно: откройте [24projects.ru](https://24projects.ru/).

### Исходный код

С установленным Git:

```bash
git clone --branch main https://github.com/MrDary-art/Mirnaya-Mafia.git
cd Mirnaya-Mafia
```

Без Git: на странице репозитория выберите **Code → Download ZIP** и распакуйте архив. Это исходники, для запуска которых нужны зависимости и сборка frontend.

Если используются ресурсы Git LFS, установите Git LFS и загрузите их:

```bash
git lfs install
git lfs pull --include="frontend/**" --exclude="models/**"
```

### Установочный комплект

Откройте [GitHub Releases](https://github.com/MrDary-art/Mirnaya-Mafia/releases/latest). Для ручной установки скачайте из одного релиза архив `arena-<version>.zip`, его `.sha256` и установщик `install-ubuntu.sh` или `install-windows.ps1`.

Автоматические архивы GitHub **Source code** не заменяют установочный комплект. Опубликованный релиз может отличаться от текущей ветки `main`; для новых изменений комплект собирают из исходников.

## 4. Установка на своём сервере

<a id="ubuntu-site"></a>

### Ubuntu

Установщик рассчитан на Ubuntu 22.04, 24.04 и 26.04 LTS x86-64. Минимальные ориентиры — 2 ГБ RAM и 8 ГБ свободного места; модели, записи и нагрузка требуют дополнительных ресурсов. Для публичного сайта подготовьте домен с A-записью на сервер и доступные входящие TCP 80 и 443.

Подключитесь по SSH, проверьте `cat /etc/os-release` и `df -h /`, затем выполните:

```bash
bash -c 'f=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/MrDary-art/Mirnaya-Mafia/main/install/install-ubuntu.sh -o "$f" && sudo bash "$f"; rc=$?; rm -f -- "$f"; exit "$rc"'
```

Мастер скачает опубликованный комплект, проверит контрольную сумму и запросит адрес сайта и новые учётные данные администратора. ИИ и почту можно настроить сразу или позже в админке. Стандартная папка — `/opt/master-negotiations`.

Проверьте установку:

```bash
sudo /opt/master-negotiations/arena status
sudo /opt/master-negotiations/arena doctor --speech
```

<a id="windows-site"></a>

### Windows

Поддерживаются Windows 10 22H2/11 x64. Скачайте три файла одного релиза и откройте PowerShell от имени администратора в папке с ними. В папке должен быть один выбранный комплект:

```powershell
$sha = ((Get-Content -Raw .\arena-*.zip.sha256).Trim() -split '\s+')[0]
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-windows.ps1 -Bundle (Resolve-Path .\arena-*.zip).Path -BundleSha256 $sha
C:\ProgramData\MasterNegotiations\arena.cmd status
```

По умолчанию сайт устанавливается в `C:\ProgramData\MasterNegotiations`. Для видеосвязи с других устройств настройте HTTPS.

<a id="mail-setup"></a>

### Подключения

В `/admin` задайте поддерживаемого провайдера ИИ, модель и ключ, затем проверьте подключение. Без ИИ доступны теория и готовые сценарии; онлайн-практика требует доступного провайдера.

Для почты укажите отправителя и SMTP-параметры, отправьте проверочное письмо и убедитесь в доставке перед включением. Соответствующие функции подтверждения адреса, восстановления пароля и уведомлений зависят от настройки почты. Вход по логину сохраняется.

Для корректных ссылок в письмах задайте фактический адрес установки в `PUBLIC_BASE_URL`. Не добавляйте ключи, пароли и содержимое `.env` в Git.

<a id="remote-whisper"></a>

### Внешний Whisper для записей встреч

В админке создайте код подключения. На отдельной машине с NVIDIA GPU установите worker: с ролью `--role whisper-worker` на Ubuntu или `-Role whisper-worker` на Windows. Он подключается к сайту по исходящему HTTPS. Полные команды и требования: [установка внешнего Whisper](docs/INSTALLATION.md#внешний-whisper).

## 5. Запуск из исходного кода

Нужны Git, Python 3.12, Node.js 22 и npm. Backend и frontend запускаются в двух терминалах. Не заменяйте конфигурацию существующей рабочей установки файлами примера.

### Backend

Из корня проекта:

```bash
cd backend
python -m venv .venv
```

Активируйте окружение:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
# Linux / macOS
source .venv/bin/activate
```

Затем:

```bash
python -m pip install -r requirements.txt
```

Создайте `backend/.env` на основе `backend/.env.example`, задайте собственный `SECRET_KEY` и проверьте `DB_PATH`. В примере это `../data/arena.db` относительно папки backend. Смена пути может открыть другую, пустую базу.

Из папки backend:

```bash
python -m alembic upgrade head
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### Frontend

Во втором терминале из корня проекта:

```bash
npm ci --prefix frontend
npm run dev --prefix frontend -- --host 127.0.0.1 --port 5173
```

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd`. Откройте [локальный сайт](http://127.0.0.1:5173/). Vite передаёт запросы `/api` в backend на порту 8000.

Один запуск uvicorn не создаёт администратора с известным паролем. Для административного доступа используйте предусмотренную процедуру настройки установки.

### Проверка и сборка

```bash
# Из backend с активированным Python-окружением
python -m pytest -q

# Из корня проекта
npm run build --prefix frontend
python install/build_release.py --version local-20261020
```

Комплект и контрольная сумма появятся в `release-artifacts`. Модели устанавливаются отдельно предусмотренными механизмами установщика.

## 6. Обновление и обслуживание

Завершите активные встречи и создайте резервную копию:

```bash
sudo /opt/master-negotiations/arena backup
sudo /opt/master-negotiations/arena status
sudo /opt/master-negotiations/arena logs
```

Обновление через установочный комплект:

```bash
sudo /opt/master-negotiations/arena update --bundle /absolute/path/arena-VERSION.zip --sha256 SHA256_ИЗ_ФАЙЛА
```

Подставьте версию, путь и сумму своего релиза. На Windows используйте `C:\ProgramData\MasterNegotiations\arena.cmd` и соответствующие пути. Для отдельно выданного пакета обновления выполняйте инструкцию именно этого пакета.

Не удаляйте `data`, `private`, ключ установки и резервные копии при обновлении. Исходный ключ нужен для чтения зашифрованных настроек. Изменения схемы применяются миграциями; один архив кода не гарантирует откат схемы. Сохраняйте резервную копию вне папки установки.

При проблемах проверьте службы, журнал и `/api/health`. После обновления frontend перезагрузите страницу через Ctrl+F5. Подробности: [установка](docs/INSTALLATION.md), [обслуживание](docs/INSTALLATION_DETAILS.md).

## 7. Как удалить

### Временно выключить сайт

На Ubuntu:

```bash
sudo systemctl stop arena-api.service arena-web.service
```

Включить обратно:

```bash
sudo systemctl start arena-api.service arena-web.service
```

Остановка не удаляет пользователей, отчёты и настройки.

### Полностью удалить с Ubuntu

Команды относятся только к установке в `/opt/master-negotiations`. Удаление стирает базу, ключи, записи и резервные копии внутри папки. Нужные данные заранее сохраните в другом месте командой `arena backup`.

Сначала проверьте пути служб:

```bash
sudo systemctl show arena-api.service arena-web.service -p ExecStart -p WorkingDirectory
```

Если обе службы относятся к нужной установке, выполните по порядку. После ошибки остановки не переходите к удалению:

```bash
sudo systemctl disable --now arena-api.service arena-web.service
sudo rm -f -- /etc/systemd/system/arena-api.service /etc/systemd/system/arena-web.service
sudo systemctl daemon-reload
sudo rm -rf --one-file-system -- /opt/master-negotiations
systemctl show arena-api.service arena-web.service -p LoadState
```

Ожидается `LoadState=not-found`. Домен и DNS удаляются отдельно у провайдера. Для другого пути установки, Docker или ручного запуска эти команды нужно адаптировать после проверки.

### Полностью удалить с Windows

В PowerShell от имени администратора проверьте службы:

```powershell
Get-CimInstance Win32_Service | Where-Object { $_.Name -in @('arena-api','arena-web') } | Select-Object Name, State, PathName
```

Для стандартной установки пути должны вести в `C:\ProgramData\MasterNegotiations\services`. После резервного копирования:

```powershell
$ErrorActionPreference = 'Stop'
$arenaInstallPath = 'C:\ProgramData\MasterNegotiations'
if ((Resolve-Path -LiteralPath $arenaInstallPath).Path -ne $arenaInstallPath) { throw 'Проверьте путь установки' }
foreach ($serviceName in @('arena-api','arena-web')) {
    $service = Get-Service -Name $serviceName -ErrorAction SilentlyContinue
    if ($service) {
        Stop-Service -Name $serviceName -ErrorAction Stop
        & "$arenaInstallPath\services\$serviceName.exe" uninstall
        if ($LASTEXITCODE -ne 0) { throw "Не удалось удалить службу $serviceName" }
    }
}
Remove-Item -LiteralPath $arenaInstallPath -Recurse -Force
```

При нестандартной установке сначала определите фактический путь. Отдельный worker не удаляется вместе с сайтом; инструкция для него находится в [обслуживании](docs/INSTALLATION_DETAILS.md#удаление-на-windows).

### Удалить локальную копию

Остановите uvicorn и Vite через Ctrl+C в их терминалах. Сохраните нужную базу и настройки, затем удалите папку проекта через файловый менеджер. Если база, записи или модели настроены вне проекта, их удаляют отдельно после проверки путей.

### Удалить пользователя или компанию

Это административная операция с данными, а не удаление программы. Выполняйте её через предусмотренные разделы администрирования, проверяя выбранный аккаунт или компанию. Массовая очистка базы не требуется для обновления кода.
