# Арена Переговоров

Интерактивный тренажёр переговоров: живая видеоарена с людьми и соло со голосовым ИИ. Фронтенд лёгкий, LLM крутится локально.

## Что уже работает

- Главное меню с двумя режимами, тёмным UI (glassmorphism / неон)
- **ИИ-тренажёр**: сценарии, роль, диалог с «Ешкой» через локальную Ollama, голос браузера (STT/TTS), отчёт судьи
- **Сетевая арена**: комнаты по коду, WebRTC 1:1, скрытые цели, протокол реплик, судейский JSON-«файлик»
- Настройки URL ядра — чтобы статика на Vercel ходила в Cloudflare Tunnel

## Стек

| Слой | Сейчас |
| --- | --- |
| Фронт | HTML/CSS/JS, хостинг Vercel/Netlify |
| Сервер | Node 18+, Express, WebSocket |
| LLM | Ollama (`llama3.1` по умолчанию) |
| Речь | Web Speech API (Chrome); Whisper/локальный TTS — следующий слой |
| Медиа | WebRTC + STUN |

## Запуск

1. Установите [Ollama](https://ollama.com) и модель:

```bash
ollama pull llama3.1
```

2. Сервер арены:

```bash
cd negotiation-arena
npm install
npm start
```

Откройте http://localhost:8787

3. Если фронт на Vercel, а ядро дома — поднимите туннель к порту 8787 и вставьте URL в **Настройки**.

Переменные окружения:

- `PORT` — порт HTTP (по умолчанию 8787)
- `OLLAMA_URL` — `http://127.0.0.1:11434`
- `OLLAMA_MODEL` — имя модели Ollama

## Архитектура

```
Браузер  --HTTPS-->  Vercel (статика)
   |  WebSocket / REST
   v
Cloudflare Tunnel  -->  ноутбук (Express + Ollama + позже Whisper/TTS)
```
