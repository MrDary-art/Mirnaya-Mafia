# Референсы оформления

Одна композиция объединяет два референса: Solana вверху публичной страницы, Solflare ниже; после входа остаётся Solflare с жёлтым акцентом. Основной фон — тёмный Solflare (#080b0d). Публичные страницы используют оранжевую палитру, градиенты и мягкие края подсветки. Содержимое, логотипы и финансовые функции сайтов не переносятся.

| Тема | Публикация | Перенесённый визуальный язык |
| --- | --- | --- |
| Maxi · Solflare | https://maxibestof.one/websites/77659-solflare | Чёрно-белые поверхности, жёлтый акцент, большие скругления, контрастная типографика, парящая тёмная карточка. Карточка нарисована CSS с содержимым «Арены»; это адаптация композиции под симулятор. |
| Webflow · Solana | https://webflow.com/made-in-webflow/website/solana-rebuild | Анимированный объёмный объект, перекрашенный в оранжевый градиент. Референс — Solana Rebuild, автор Dhruv Sachdev, https://solana-rebuild.webflow.io/. |

## Локальные медиа Solana

- `solana/ribbon.mp4` — исходное видео первого экрана Webflow-референса, 1280×720, 7,23 с, 664 638 байт.
- Источник: https://assets.website-files.com/626912d685fd092a4de0ab21/626939050934c33c51f2dcbb_2781013183-transcode.mp4
- `solana/poster.jpg` — кадр того же видео на второй секунде для предпросмотра и статического отображения.
- Получены 23 сентября 2026 года. Авторство исходного видео принадлежит создателям референса; собственной лицензии на него проект не заявляет.

Базовый цвет объекта задаётся CSS-фильтром тонирования; маски растушёвывают все четыре края, а экранное смешивание убирает чёрную подложку видео. Светлый режим дополнительно адаптирует его к светлой поверхности. Видео, постер и вся остальная графика обслуживаются локально. Цвета, формы и анимации реализованы в `src/designs.css`, `src/SignatureBackground.tsx` и `src/useSectionReveal.ts`; композиция лендинга — в `src/Landing.tsx`, настройки — в `src/appearancePreferences.ts`.

Прежняя спираль и её источники: [vara/README.md](vara/README.md).
