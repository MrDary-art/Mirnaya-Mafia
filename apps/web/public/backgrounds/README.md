# Референсы оформления

Три каталога содержат множество сайтов. Для оформления «Арены» выбраны конкретные публикации; содержимое, логотипы и финансовые функции этих сайтов не переносятся.

| Тема | Публикация | Перенесённый визуальный язык |
| --- | --- | --- |
| Lapa · Aave | https://www.lapa.ninja/post/aave-2/ | Светлый фон, крупный гротеск, круглые кнопки, шесть растущих колонн с вращающимися двухцветными дисками. Геометрия заново нарисована CSS. |
| Maxi · Solflare | https://maxibestof.one/websites/77659-solflare | Чёрно-белые поверхности, жёлтый акцент, большие скругления, контрастная типографика, парящая тёмная карточка. Карточка нарисована CSS с содержимым «Арены»; это адаптация композиции под симулятор. |
| Webflow · Solana | https://webflow.com/made-in-webflow/website/solana-rebuild | Чёрные поверхности, мятные кнопки, фиолетово-бирюзовый объёмный объект. Референс — Solana Rebuild, автор Dhruv Sachdev, https://solana-rebuild.webflow.io/. |

## Локальные медиа Solana

- `solana/ribbon.mp4` — исходное видео первого экрана Webflow-референса, 1280×720, 7,23 с, 664 638 байт.
- Источник: https://assets.website-files.com/626912d685fd092a4de0ab21/626939050934c33c51f2dcbb_2781013183-transcode.mp4
- `solana/poster.jpg` — кадр того же видео на второй секунде для предпросмотра и статического отображения.
- Получены 23 сентября 2026 года. Авторство исходного видео принадлежит создателям референса; собственной лицензии на него проект не заявляет.

Базовый цвет объекта меняется сдвигом оттенка видео; светлая версия дополнительно адаптирует его к светлой поверхности. Видео, постер и вся остальная графика обслуживаются локально. Цвета, формы и анимации приложения реализованы в `src/designs.css` и `src/SignatureBackground.tsx`; настройки — в `src/appearancePreferences.ts`.

Прежняя спираль и её источники: [vara/README.md](vara/README.md).
